## 构建与素材

`pnpm build:demo` 通过 TypeScript 检查及 Vite 构建；修正后脚本为 `index-CWPXEvy6.js`。Impeccable detector 在交接前运行一次，结果为 `[]`；修正后没有重复运行。共用旧样稿的公开作品及几何样本，没有新增图库副本。12 张截图已逐一目视确认，来源元数据嵌入后扫描为 20 张 raster、0 张缺失。

## 实际操作证据

- 父文件夹按原图去重：两个子文件夹各 2 张，父级 3 张；默认包含子层，关闭后父级直接成员为 0 张。
- 「人像」与「长发」同时满足得到 3 张；文字和标签同时参与查找。手工标签与多文件夹归属可编辑，原图总数保持 8 张。新文件夹命名输入获得焦点，空范围有可返回全库的提示。
- 拖出局部、输入比例、加入参考、返回查找均可操作；返回保留查找条件和所选图焦点。切换资料库保留本次参考。
- 局部比例左 30%、上 20%、宽 40%、高 35% 的预览显示 384 × 376；A 的取用阶段中，先点击标题让焦点回到 BODY，再按 Right，方案仍为 A，四个输入值不变。
- 参考组列表及 A 的绘画参考阶段中，BODY 焦点按 Right 均保持所在页面。找图页面相同操作仍从 A 切到 B；页脚按钮仍可显式切换方案。
- 后层「神奈川冲浪里」参考首次点击锁定立即显示「位置已锁定」，移动手柄禁用。后层「细线网格」首次缩小从 150.6px 变为 130.52px，同时正确置前。
- 拖动标题从画面坐标 (904,232) 到 (964,262)，参考在并排画布内从 left 50.912px / top 57.1797px 变为 left 110.912px / top 87.1797px；手柄方向键也可移动。
- 完成保存向导后，首次移除后层细线参考，成员由 2 减至 1。重新打开已保存组并确认放弃本次修改，恢复为 2。保存与重开后的 DOM 布局完全相同：细线 width 308.1px / left 568.785px / top 141.142px / layer 1 / 未锁定；海浪 width 340px / left 309.202px / top 53.6316px / layer 2 / 已锁定。
- 手机宽度 390px 的图片墙保持两列，documentWidth = viewportWidth = 390；局部取用控件可以滚动到达。实际构建通过私人 Tailscale Serve 地址加载。

## 独立评审

首次 disposition 为 `fix`，列出窗口首次控制点击及全局方向键上下文两项。一次修正批次后，节点按稳定身份保持 DOM 顺序，保存数组仍决定层级；方案方向键仅在找图背景启用。同一评审的 verdict 另行记录；此处的运行证据不替代画师体验判断。

## 实际边界

响应式手机验证来自桌面浏览器的窗口模拟，未宣称实体手机的系统输入和桌面置顶验证。没有复测本地文件选择器，不以 8 张样本判断大图库性能。公开素材标签为人工示例。内存数据刷新即重置；网页参考窗口不证明 Tauri、原生置顶、ICC／DPI、超分、备份或同步可行性。正式界面结构仍待画师试用决定。
