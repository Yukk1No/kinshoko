# 多资料库验收（#49）

本地自动验证使用临时目录、真实 SQLite 与真实图片文件，直接调用 Rust 核心公开接口；界面测试模拟 IPC 和事件，检查窗口状态与请求所属的资料库。测试不下载打标大模型。

## 已实现的行为

| 工单验收项 | 验证依据 |
|---|---|
| 登记、取消登记、切换资料库；记住上次打开的库 | `tests/device_libraries.rs` 的登记、切换与重启测试；`tests/device.rs` 的取消登记测试；`src/App.test.tsx` 的登记与取消登记测试 |
| 切换时结束旧库未完成的导入，保留成功项 | 核心测试启动 2000 项导入，切换返回时已收到取消后的完成事件；旧库成功图片仍在，新库为空 |
| 旧请求的结果不会混入新库 | 命令携带资料库 ID，核心拒绝旧 ID；界面延迟返回图片墙、文件对话框、搜索候选与条件树，并推送旧库进度，确认新工作区不被覆盖 |
| 打标任务与搜索缓存跟随活动库 | 切换和取消当前登记在后台等待旧打标服务退出；搜索缓存绑定具体库句柄；打标状态与暂停、继续、下载请求携带库 ID，界面测试确认其他库的状态被忽略 |
| 移动整个资料库文件夹后重新登记，身份与整理结果不变 | 核心测试保留设备登记、关闭库、移动目录后在新位置重新登记；逐项比较资料库与参考图 ID、原图字节、文件夹、备注、人工标签，确认登记更新位置且无重复 |
| 不可用资料库有明确提示 | 核心测试移动已登记目录以模拟盘不在，保留登记并显示移动盘与重新登记提示；失败切换仍保留原活动库与上次选择；界面测试检查不可用标记、原因与管理入口 |

取消登记只移除本设备的位置记录。原图、SQLite 和整理结果仍在原目录。资料库身份从 `library.sqlite` 读取，本工单没有新增数据库迁移。

## 本地检查

附件要求的检查：`npm ci`、`npm run vite:build`、`cargo fmt --all --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace`、`npm run bindings`（生成后 `src/bindings` 无差异）、`npm run typecheck`、`npm test`。

受限执行环境下，将 `TEMP`、`TMP` 指向已忽略的 `target/test-tmp`，并用 `CARGO_INCREMENTAL=0` 避免临时目录权限和增量硬链接影响检查结果。

## 尚需人工验证

- 实体移动盘断开、接回后的路径与权限由 Windows 和设备决定。自动测试已覆盖目录缺失与失败切换；实体拔插仍需在装有应用的电脑上复测。
- 画师电脑上的真实大资料库、驱动与模型会影响停止当前打标图和释放句柄的等待时间。自动回归使用测试打标服务，未下载大模型，也未在画师电脑上运行。

建议人工流程：登记两个库并来回切换；在导入或打标期间切换；取消当前登记后移动完整文件夹，再从新位置登记；拔出另一个库所在移动盘，确认仍可操作当前库，接回后刷新并重新打开。
