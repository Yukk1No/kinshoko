# 开发机与画师电脑：本地备份与恢复（#69）

准备两个已登记的资料库 A、B（各有几张图、文件夹、备注、标签、个人近似对应表条目，A 有一张在回收站里），一个跨 A、B 的参考组和一个只引用 A 的参考组；一块移动盘或 U 盘作备份目标。不要同时开着别的 kinshoko.exe。范围计算、增量复制、租约、保留策略、恢复与往返检查已由 `crates/kinshoko-core/tests/backup_*.rs` 覆盖，这里只查要真机与真时间的部分。

- [ ] 设置 →“备份”→“选择备份目录…”选移动盘上的文件夹：显示“备份到 …”；“马上备份”显示“正在备份：原图 n／m”，完成后“上次备份”是现在的本地时间；移动盘上出现 `kinshoko-backup\snapshots\<日期-时间-…>\manifest.json` 与 `kinshoko-backup\originals\`
- [ ] 选“只备份所选资料库”只勾 A：列出带上的参考组与容量；取消“一起备份参考组还引用的资料库”后列出“参考组「…」引用的「B」不在这次备份里”
- [ ] 再导入一张图后“马上备份”：很快完成，`originals` 下只多出一个文件
- [ ] 原文件复制期间新增图并存入已有参考组：本次备份恢复后仍使用备份开始时的组引用，往返检查通过（公共接口并发回归已覆盖）
- [ ] 备份进行中在 A 的回收站里永久删除一张图：备份完成且完整；之后重开 A，原文件才从 `originals\` 消失
- [ ] 当天第二次关闭主窗口不再自动备份；把系统日期调到第二天（或等到第二天）后第一次关闭主窗口，托盘提示“正在备份…”，主窗口重开后“上次备份”更新
- [ ] 不碰键盘、鼠标与笔 10 分钟以上（当天还没备份时）：自动备份一次
- [ ] 拔掉移动盘后托盘“退出”：进程很快结束；重新启动后主窗口底部提醒“备份没有完成：备份目标不在……下次退出或空闲时再试”，设置里也写出原因；接回移动盘、下次关闭主窗口后自动备份成功，提醒消失
- [ ] 托盘“退出”（当天还没备份、移动盘在）：先备份完再结束进程
- [ ] “从备份恢复…”选一个快照、选一个空文件夹：显示“往返检查通过：原图 … 张哈希一致、整理信息 … 张表、参考组 … 个一致”；资料库列表多出“A（恢复）”“B（恢复）”，活动资料库没变；参考组列表多出同名的新参考组，打开后成员来自恢复出的库（局部与摆放不变）；原来的资料库与参考组不变
- [ ] 切换到“A（恢复）”：图片、文件夹、备注、标签、回收站与个人近似对应表都在；原图 1:1 显示正常
- [ ] **画师确认**（验收约定“导入与数据保护”）：在画师电脑上对真实资料库备份到另一块盘、恢复，浏览确认素材与参考组都在，记下备份与恢复耗时、备份容量

已知限制：备份目标只支持本地目录（含移动盘）；备份目录不在时不会改备份到别处；读不到的资料库（例如所在移动盘没插）这次跳过并在结果里列出，快照仍算完整；恢复出的资料库名称加“（恢复）”，文件夹名加恢复日期。
