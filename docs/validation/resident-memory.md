# 常驻内存实测

记录 Kinshoko 常驻托盘时的内存占用（#61，ADR-0004 的后续）。每次进程模型或主窗口生命周期有变化时补一行。

## 测法

release 构建（`npx tauri build --no-bundle`）的 `kinshoko.exe`，设置 `KINSHOKO_SKIP_AUTOSTART=1` 避免把测试版登记为开机启动。启动后等 8 秒，统计 `kinshoko.exe` 及其全部子进程（WebView2 的 `msedgewebview2.exe`）的工作集与私有内存；随后向主窗口发送关闭消息，再测；最后再启动一次，由单实例转给常驻进程重新打开主窗口，再测。

## 结果

| 日期 | 提交 | 机器 | 状态 | 进程数 | 合计工作集 | 合计私有 |
| --- | --- | --- | --- | --- | --- | --- |
| 2026-10-06 | #61 分支 | 开发机：Ryzen 7 5800X、32 GB、RTX 4070 SUPER、WebView2 154 | 主窗口打开（空界面） | 7（WebView2 6） | 379 MB | 167 MB |
| | | | 关闭主窗口、仅托盘常驻（6 秒与 36 秒后相同） | 1（WebView2 0） | 37 MB | 5.6 MB |
| | | | 从常驻进程重新打开主窗口 | 7（WebView2 6） | 378 MB | 169 MB |

关闭主窗口后 WebView2 进程全部退出，常驻只剩 `kinshoko.exe` 本身；重新打开后回到与首次打开相同的水平，没有累积。
