## 红→绿记录

新增或更新行为检查均先失败，再改生产实现：

- 单击打开：旧程序找不到“原图查看器”；修复后原图、Esc 返回、滚动位置和焦点通过。
- Rail 上下文：旧程序找不到“主导航”；修复后切换参考组保留图片墙和查找，再点收起，回文件夹入口通过。
- 连续重排：旧实现中途卡片宽度仍 238，期望大于 238 失败；修复后两次宽度变化与阅读偏移通过。
- 钉图 Esc：旧行为的活动集合仍含 P1/P2；修复后仅 P2 保留。
- 标签分组条：旧程序找不到标签分组 toolbar；修复后添加/取消条件且文件夹范围保持通过。
- 资料库操作入口：旧壳找不到紧凑入口；修复后登记、切换和取消登记通过。
- 无活动资料库的截图入口：迁移中缺少历史面板；补回后截图历史与钉剪贴板入口通过。

测试文件：`src/App.test.tsx`、`src/desktop/PinView.escape.test.tsx`。其他标签/批量整理检查的选择动作改为空格或 Ctrl，与新交互相同。过时的“动画期间冻结宽度”检查由主窗口连续重排行为检查替代。
