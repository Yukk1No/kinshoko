### 环境与真实步骤

Windows 11 Pro 10.0.26300；RTX 4070 SUPER 驱动32.0.16.1714；WebView2/匹配 EdgeDriver154.0.4258.62。正式程序观测 DPR 为1.1041666269302368，没有覆盖它。初始 CSS 视口1281×801。只有 headless 原型设置匹配的 DPR 参数；该参数不代表改变或验收 Windows 物理缩放。环境原始清单与二进制 SHA-256 均已保存。

1. 正式程序新建资料库，导入43张真文件，包括2400×1600网格、100×600竖图和600×100横图。关闭导入报告后截图。
2. 检查6px圆角、43张真实结果数与图片大小滑块。真实键盘把目标宽度240→420→240，卡片宽度228.25→464.5→228.25。
3. Ctrl选2张，真实新建文件夹并归入。切换范围、查找无匹配文字、清除条件后仍保留文件夹范围，再回全部。
4. 单击同一网格图，检查适应派生图与原图设备像素1:1、像素起点、超过200%用原图、离线字体。返回后保留卡片焦点。
5. 滚动到720，用Enter打开、Esc返回；滚动仍720且焦点回到相同卡片。侧栏收起/展开与原生窗口宽度往返保持同一锚点偏移；侧栏动画采集到20种卡片布局宽度。
6. 打开两张真实原生钉图，在一张中按Esc；该窗口关闭，另一张与主窗口保持打开。
7. 未改源码的固定原型读取相同样本/顺序/离线字体，以相同初始视口与DPR执行密度、单击、键盘返回、侧栏和窗口变化步骤，保存观测而不伪造完全一致。
