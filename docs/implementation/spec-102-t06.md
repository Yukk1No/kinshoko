## 实现

- **精确查找**（[`ExactToggle`](../../src/search/ExactToggle.tsx)）：Base UI `Toggle` + `Tooltip`，32 × 32、圆角 8，放在 40 高、圆角 12、右内边 4 px 的查找框尾部，同心。字形为 16 px 网格居中的两道波浪（含相近）／两道直线（仅精确），切换时波浪压扁淡出、直线展开。开启时 `--exact-on-bg`／`--exact-on-inset`／`--exact-on-ink`，日夜两套令牌写在 `src/styles.css`。无障碍名称仍为“精确查找”，状态由 `aria-pressed` 表达；提示说明当前状态与按下后的结果。
- **图片大小浮岛**（[`DensityIsland`](../../src/wall/DensityIsland.tsx)）：从顶栏移到 `app-main` 右下角，`role="group"`、名称“图片大小”，两端小图／大图图标。主区窄于 600 px 时只把滑条缩到 96 px，不再隐藏。
- **滑条**（[`DensitySlider`](../../src/wall/DensitySlider.tsx)）：仍是原生 `range`，提交逻辑未改（拖动松手提交；键盘停手 220 ms 后提交；回到原值撤掉预览）。新增 `--fill` 行内变量画已走过的一段，样式见 `src/shell/main-window.css` 的 `.k-range`。
- **导入**（[`SplitButton`](../../src/ui/SplitButton.tsx)、[`ImportSplit`](../../src/ui/ImportSplit.tsx)）：不带文字即安静形态 `is-quiet`，只留图标与箭头、无底色、悬停 `--hover`；菜单内容不变；导入中 `aria-busy` 并让图标呼吸（减少动画时不动）。
- **张数**保留在顶栏。
- `e2e/shared-personal-approx.mjs`、`e2e/spec78-combination-workflow.mjs` 改按无障碍名称找精确查找开关（旧的文字按钮与 `.search-exact` 已移除）。
- `design/ui-system/README.md`：组件对照加入精确查找、图片大小；“按钮”一节改写导入、新增精确查找、浮岛与滑条。
