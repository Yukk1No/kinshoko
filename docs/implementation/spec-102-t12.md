## 做了什么

### 标题行“图库 ＋”（`src/library/LibraryPicker.tsx`）

- 侧栏标题行改为“图库”与一个 ＋ 菜单：打开图库… / 新建图库… / 管理图库，取代图库切换下拉框（单选列表去掉）。按 ADR-0008，界面上不再有“当前图库”；“打开图库…”仍登记并打开所选文件夹（与原来相同），“管理图库”对话框不变（列出登记、原因、重新连接、移除）。
- 收起侧栏后顶栏不再放图库菜单（原来放的是切换下拉框，切换没有了）。

### Finder 式分组（`src/library/WorkspacePane.tsx`、`src/library/SidebarPane.tsx`）

- 顶部固定“全部图片”，带各已连接图库的合计张数。
- 每个图库一行：箭头、图库名（小号、加粗、字距略宽）、张数，悬停出现 `⋯`；路径只在名称的悬停提示里（原来名称下的一行路径去掉）。点名称选中该库的全部。
- 库内依次为未归类与文件夹树，不再有“文件夹”小标题和标题上的 ＋。新建文件夹在 `⋯` 菜单里：选中该库的某个文件夹时建在它里面，否则建在顶层；折起的图库随之展开。原来拖到“文件夹”标题上移到顶层，改为拖到本库的图库名上。
- `⋯` 目前只有“新建文件夹”。菜单项写在 `LibraryMenuItems` 里，#114 在那里补在资源管理器中打开 / 重新连接 / 从列表移除，并让图库标题的右键菜单用同一组菜单项。
- 展开规则：选中某个图库内的范围时只展开该库、其他折起；选“全部图片”时全部折起；所选图库变了才重置，期间点箭头的临时展开保留（同一库内换文件夹不收起别的库）。
- 弹簧加载：拖动图片或文件夹悬停在折起的图库上 600 ms 自动展开；离开该图库（进出按计数，不依赖 `relatedTarget`）、在任何地方放下或拖动结束（`drop` / `dragend`）后恢复折起。已展开的图库不受影响。
- 每个已连接图库的目录都能直接整理（改名、移动、拖入），沿用 #112 的按需切换；文件夹只能在本库内移动，拖到别的库的文件夹或图库名上不做任何事（拖动时多带一个 `application/x-kinshoko-folder-library` 类型记下所属图库）。
- 未连接的图库：名称变淡、带警示点、没有箭头，下方一行“未连接 · 移动盘接回后可用 · 重新连接”，原因在这一行的悬停提示里；“重新连接”与原来相同，重新检查各图库。
- 回收站（侧栏底部）：选中某库内的范围时是该库的回收站，显示“回收站 · 库名”；选“全部图片”时显示“回收站 · 全部图库”与各库合计，点开在下方按库分组列出各库的回收站（只有一个已连接图库时直接打开它）。原来的 `activeLibraryId`（“当前图库的回收站”）去掉。
- “含子文件夹”开关保留在目录下方。

### 详情面板的多选（#112 留下的缺口，`src/App.tsx`、`src/library/SelectionPanel.tsx`）

- 原来详情面板只在选中的图属于窗口打开时的那个图库时才显示批量整理。现在先定“整理哪个图库”：范围是某个图库时就是它；“全部图片”下选中的图都只有同一个图库的来源时是那个库。多选时任何一个图库都可以批量放入文件夹、加标签、删除 / 恢复、永久删除，请求带上那个图库（后端按需切换）。只选一张且不在窗口打开的图库时仍走原来的来源整理（`WorkspaceSources`）。
- 主窗口的 `SelectionPanel` 经 `workspace_sidebar` 读所选图库的目录，不再用要求“活动资料库”的 `sidebar`：整理过别的图库、后端可写句柄切走后，目录仍读得到。

- `design/ui-system/README.md`（组件对照、一体化顶栏、侧栏布局）与 `design/ui-system/copy-map.md` 按方案 D 更新。
