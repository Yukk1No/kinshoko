**没有做的：DOM 节点池（把一个卡片节点改绑到另一张图）。** 这会在换绑时换 `<img src>`（旧图闪现或白块，并与 #110 的占位图交叠）、打乱按 id 关联的焦点恢复、选择、拖动与重排动画，风险大于收益；在 trace 证明节点创建是瓶颈之前不做。

### 鼠标滚轮插值与惯性

[`smoothWheel.ts`](../../src/wall/smoothWheel.ts)，在图片墙滚动容器上以非被动 `wheel` 监听接管：

- **每格目标 + 临界阻尼弹簧**：每格把目标推远一格，同时给速度加上 ω·格距（ω = 1/τ，τ = 120 ms）。从静止起步时误差按 e^(−t/τ) 收敛：一格后 120 ms 走完约 63%，约 360 ms 走完 95%，不越过目标。每帧用临界阻尼弹簧的精确解推进，与帧间隔无关（60／170 Hz 走同一条曲线）。
- **连续快滚叠加**：新的一格加在当前目标上，速度叠加在正在进行的速度上。目标被滚动范围截住时改为单调收敛到边界，不冲过头。
- **输入到首次画面响应**：事件里只更新弹簧并请求一帧；下一帧（rAF 早于时间戳时按一帧计）就写入位移，不等第二帧。
- **走原生的情况**：精确式触控板（带横向分量、非整数增量，或旧式 `wheelDeltaY` 不是 120 的整数倍；同一串事件 400 ms 内后来的整格也走原生，不来回切换）；笔（不产生 wheel 事件）；Ctrl／Shift／Alt／Meta 滚轮（Ctrl 是 #111 的缩放）；按住指针期间（拖滚动条，按下时也停下正在进行的插值）；“减少动画”。
- **让出**：别处改了 `scrollTop`（键盘、滚动条、锚点恢复）时，下一帧发现位置与上一帧写入的不一致就停下，不把位置拉回去；打开查看器、Ctrl+滚轮缩放时也停下。
- 最大滚动位置按布局高度算，不读 `scrollHeight`（避免强制布局）。
