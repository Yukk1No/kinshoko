# #102 T9：导入时生成极小占位图，缩略图到达前先显示（#110）

本单覆盖 #102 故事 19：缩略图到达前先看到同色调的模糊占位，快速滚动时不满屏白块。代码起点为集成分支 `claude/project-thread-wr3c28`（`9a1bbb7`，即 `codex/spec-78-integration` 合入 4 个缺陷修复会话的结果）。#78 及其子工单未改写。

## 做了什么

- **生成**：Rust 管线为每个原文件（按 SHA-256）生成长边约 32 px 的 `sdr` 派生图。直接调用缩略图同一个 `render_sdr`：同样的色彩声明规则（moxcms）、f32 预乘 alpha 缩放与按来源分档的无损容器（8 位 WebP 或 16 位 PNG＋ICC），符合 ADR-0005。
- **缓存键**：`cache/thumbs/<管线版本>/sdr/<sha 前两位>/<sha>-p32.<webp|png>`，与缩略图同一个带管线版本的目录、不同的文件，分别缓存。管线版本变化时随旧目录一起作废；永久删除时随该原文件的派生图一起清除。
- **时机**：导入（含参考组包导入）进库后立即生成；生成失败不影响导入结果。打开资料库（`Library::open`）时后台线程按从新到旧为缺少占位图的图补生成；线程只持有弱引用，资料库关闭后停下。
- **随浏览页返回**：`ImageCard.placeholder` 与 `WorkspaceCard.placeholder` 是占位图的 `data:` 地址，随 `browse` / `workspace_browse` 一起返回，不增加逐卡片请求。浏览只读已有文件，不现场生成；还没有时字段缺省，界面只留卡片的中性底色（`--card`）。
- **界面**：卡片先显示放大模糊（`blur(12px)`、`scale(1.15)`）的占位图；缩略图到达后 160 ms 淡入并盖住它，随后占位图隐去，透明缩略图不透出占位色。重新挂载时已在浏览器缓存里的缩略图直接显示、不再淡入。到达标记直接写在节点上，不经 React 渲染。“减少动画”时不淡入。
- **遮蔽**：遮蔽中的成人内容卡片不渲染占位图，不露出它的色彩。
