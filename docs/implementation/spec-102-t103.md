# #102 T1（#103）：截图读数区分原始像素并带上 logo 的星

本单覆盖 #102 故事 1、2。代码起点为集成分支 `claude/project-thread-wr3c28`（`b9eea8b`，已含“详情页截图读原始像素”修复的合并 `ebdf429`）。实现提交为 `6e7f327`（读数、星与 `capture_readout`）与 `a1a100b`（查看器文案）。#78 及其子工单没有改写。

## 行为

- 框选时，选区完全落在一张登记为来源、未被遮挡的参考图上（结果是参考视图）时，dock 读数为 `{宽} × {高} 原始像素`，数字是钉住或复制所得结果的原始像素尺寸（钉图转过奇数个四分之一圈时宽高互换，与结果一致）。
- 跨出图片、被其他窗口或界面遮住、同时落在两张来源上，或落在遮蔽中的图上（遮蔽图不登记为来源）时，读数为 `{宽} × {高} 屏幕像素`，无星。
- 选区每变一次就重新读数（拖动中也读，松手时已就绪）；迟到的旧回复不会盖住新选区。
- 星为 `design/logo-kit/master/geometry.json` 的 `wordmark.i_star` 路径原样移植，`#E3B34F`、日夜同色，挂在“原始像素”最后一个字的右上角，约为字号一半；切到原始像素时以弹簧从 0 放大并由 −15° 转正落定，“减少动画”时直接出现。
- 查看器 1:1 按钮（无障碍名称与悬停标签）、框选读数与信息面板的“原图像素”统一为 GLOSSARY 的“原始像素”。

## 实现

- 核心：`CaptureSelection::original_pixels()`（`crates/kinshoko-core/src/desktop/capture.rs`）与完成时共用同一个“唯一未遮挡来源”判断；新类型 `OriginalPixels`。
- 应用壳：`desktop` 插件新命令 `capture_readout(region, token)`，只读冻结时登记的来源；已核对 `generate_handler!`、`build.rs` 命令列表、`desktop:default`（AllowAllCommands，框选窗口在 `capabilities/desktop.json`）与前端 `plugin:desktop|capture_readout` 四处契约。
- 前端：`CaptureOverlay` 读数、`ui/OriginalStar.tsx`、`ui.css` 的 `.k-original*`；`design/ui-system/README.md` 的 Dock“读数”一条同步。
