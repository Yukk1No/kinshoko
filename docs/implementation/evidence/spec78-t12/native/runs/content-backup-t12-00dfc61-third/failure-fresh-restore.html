      统一标签目录

      检查不同资料库的标签对应。同名和别名重合的标签保持独立；纠正对应后，各库的人工添加和否决继续独立保存。

      标签显示名称

      显示名称先用显式偏好，没有偏好时跟随默认。保存偏好会在各资料库生效；恢复默认撤回该语言的偏好。其他叫法单独用于查找。

      旧资料库名称迁移

      旧名称缺少来源记录。选择前保留旧显示；已有显式偏好继续优先。每个统一标签和语言只选一条全局规则，后接入的旧库仍须确认。取消会放弃本次草稿。

      全局标签分组

      分组在各资料库共用。按分组查找表示满足任一成员，图片标签保持原样。同名旧分组分别保留，并列出原资料库。

      近似查找

      个人规则在各资料库共用。“只这次”仅改当前查找；“以后都不展开”和“＋”保存长期判断。

      个人近似对应表还是空的。查找时关掉相近标签选“以后都不展开”，或用“＋”加相近标签，会记在这里。

      诊断

      让 WebView2 把显示器当作 sRGB、不按显示器配置文件校色。只在排查颜色问题时打开。

      只记下做了哪类操作与数量（例如导入了几项、查找用了几个条件），不记文件名、路径、标签与图片，也不会自动上传。

      更新

      当前为私有阶段，请使用新版安装包手动更新。

      从托盘退出 Kinshoko 后，运行开发者提供的新版安装包，安装到原位置。装好后重新打开，继续使用已有资料库、设置、参考组和钉图。

      自动标签模型

      换模型后已经打过标的图不会重打。没有网络时，可以导入在别处下好的模型包（zip，内含模型文件与 selected_tags.csv）。
