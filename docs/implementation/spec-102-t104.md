## 做了什么

- `src/wall/WallMenu.tsx`：菜单内容。单张：打开 `Enter` · 钉住整图 `P` · 框选局部钉住 `F1` · ─ · 放入文件夹 ▸ · 从此文件夹移出（仅文件夹范围）· 加入参考组 ▸ · 内容分级 ▸ · 查看来源（多来源时）· ─ · 移到回收站 `Del`。多张：钉住 N 张 · 复制（禁用，“一次只能复制一张”）· ─ · 放入文件夹 ▸ · 加入参考组 ▸ · 内容分级 ▸ · ─ · 移到回收站（N 张）。回收站范围：还原 · ─ · 彻底删除…。空白处：导入 ▸（图片文件 / 整个文件夹 / 从 Eagle）· 全选 `Ctrl A` · 图片大小 ▸（小 160 / 中 240 / 大 320 / 特大 400）。
- 新能力项（复制图片、在资源管理器中显示、从剪贴板导入）按工单留给 T3，本单不显示。
- `src/wall/Wall.tsx`：图片墙即 `ContextMenu.Trigger`；右键时按选择规则定出作用的卡片；菜单键 / Shift+F10 在聚焦卡片的中心派发同一个 `contextmenu`；卡片快捷键 P / F1 / Del 与 Ctrl+A。
- `src/wall/useWallActions.tsx`：钉住（从指针位置错开 28 px，最多 20 张，超过先确认）、按每张图显示的来源整理与加入参考组、彻底删除（复用 `PermanentDeleteConfirm`）。
- `src/viewer/Viewer.tsx`：`startCrop`，从图片墙进入时打开即在框选模式。
- `src/library/ImportMenu.tsx`：`control`，空白处“导入 ▸”与顶栏分体按钮走同一入口。
- `src/ui/Menu.tsx`：`MenuSubmenu`（子菜单行，右侧箭头）。

## 每个菜单项的其他入口

| 菜单项 | 其他入口 |
|---|---|
| 打开 | 单击、Enter |
| 钉住整图 / 钉住 N 张 | 卡片上按 P（新增）；查看器的“钉住整图” |
| 框选局部钉住 | 卡片上按 F1（新增）；查看器的“框选局部” |
| 放入文件夹 | 选择操作条“放入”；拖到侧栏文件夹 |
| 从此文件夹移出 | 选择操作条“移出此文件夹” |
| 加入参考组 | 详情面板来源整理的“加入组”（单张） |
| 内容分级 | 详情面板的分级（单张） |
| 查看来源 | 卡片右下角的来源按钮 |
| 移到回收站 | 卡片上按 Del（新增）；选择操作条“删除” |
| 还原 / 彻底删除 | 选择操作条“恢复”“永久删除…” |
| 导入 ▸ | 顶栏导入分体按钮；拖进窗口 |
| 全选 | Ctrl+A（新增） |
| 图片大小 ▸ | 顶栏图片大小滑条 |

多张同时“加入参考组”与“内容分级”目前只有右键菜单这一个入口（详情面板只对单张）。
