## 做了什么

### 钉图菜单窗口

- 系统原生菜单（`tauri::menu` + `popup_menu`）整个去掉。钉图窗口小且透明，菜单改由一个独立的置顶、无边框、透明、不进任务栏的菜单窗口承载：标签 `desktop-menu`，页面 `index.html?view=desktop-menu`，权限加进 `capabilities/desktop.json`。
- 右键（鼠标右键、笔侧键、笔与触摸按住不动——`PinView` 的判定不变，仍调用 `pin_menu`）时，应用壳算出菜单状态，把菜单窗口铺满**指针所在的整台显示器**，把这次菜单发给页面；页面画好后调用 `desktop_menu_shown` 才显示窗口并给它焦点。菜单在页面里从指针处弹出，Base UI 的碰撞规则让菜单与子菜单翻转、平移，留在窗口——也就是这台显示器——之内。
- 位置规则在 `kinshoko_core::desktop::menu_surface`：指针所在的显示器（左、上边含，右、下边不含）；落在显示器之间的空隙或屏幕外时用最近的那台，锚点夹在里面。窗口按物理像素放（复用钉图的 `place`，Windows 上一次 `SetWindowPos`），页面按自己的 `devicePixelRatio` 把锚点换算成 CSS 像素；移到缩放比例不同的显示器后系统改了窗口尺寸时，改回整台显示器。
- 关闭：Esc、点菜单外（同一台显示器上的透明处）、菜单窗口失去焦点（点了别的显示器或别的程序）。每次菜单有编号，过期的关闭与选择都不认。窗口用完只隐藏，下次右键复用，不重建 WebView。
- 焦点：菜单窗口拿着焦点关掉时（Esc、选中一项、点菜单外），焦点交回打开它的钉图，与原生菜单相同；因点了别的程序而失去焦点时不抢回来。“贴边隐藏”在交回钉图之后执行，照旧把焦点交还给绘画软件。
- 选中一项：页面调用 `pin_menu_action(pin, action, generation)`，应用壳先收起菜单窗口，再在别的线程上执行（沿用原 `on_menu_event` 的动作与线程规则），提示照旧显示在钉图上。

### 钉图菜单项（`src/desktop/PinMenu.tsx`）

水平翻转 `H` · 垂直翻转 `V` · 顺时针旋转 90° `R` · 逆时针旋转 90° `Shift R` · ─ · 原始大小（100%）· 透明度 ▸（100%～10%，当前一档打勾，行尾显示当前值）· 锁定位置与大小（勾选）· ─ · 截图钉图：收藏到… / 复制；资料库钉图：显示这张图（安全模式下已遮蔽，仅遮蔽时）/ 存回参考组「…」（仅来自参考组时）· ─ · 在 Kinshoko 中打开 · 加入参考组 ▸ · 贴边隐藏 · ─ · 关闭钉图 `Esc`。

原生菜单的项逐项保留（文字“收藏（还没有资料库）”按 UI 用词改为“收藏（还没有图库）”）。新增四项：

- **在 Kinshoko 中打开**：资料库钉图打开主窗口，在查看器里显示这张参考图（参考视图，按当前安全模式经 `workspace_image` 读取，读不到时提示原因）；截图钉图打开主窗口的截图历史。主窗口可能还没建好，请求先留在应用壳里（`take_open_request`），与“收藏到…”的做法相同。
- **加入参考组 ▸**：子菜单打开时才读参考组列表；选中后把这一个钉图（保留此刻的局部与摆放）加进那个参考组（`ReferenceGroups::save_pins` 只传这一个），其他成员不变，钉图记下成员关系。截图钉图显示“截图要先收藏进图库，才能加入参考组”。
- **贴边隐藏**：与 F4／托盘“贴边隐藏／显示钉图”相同（全部钉图）。
- **关闭钉图** `Esc`：与原生菜单的“关闭钉图”相同。

### 截图历史条目菜单（`src/desktop/CaptureHistoryPanel.tsx`）

主窗口里每一条截图都是 Base UI `ContextMenu`：钉住 · 复制 · 收藏到… · ─ · 删除（危险项置底红字）。“复制”是新入口（应用壳新命令 `copy_capture`，与钉图菜单“复制”同一实现），条目上同时加了“复制”按钮。

### 其他

- `src/ui/Menu.tsx`：`MenuCheckboxItem`（勾选行，与 `MenuRadioItem` 同样式）。
- `src/App.tsx`：接住“在 Kinshoko 中打开”（`src/desktop/openInKinshoko.ts`）。
- `src-tauri/build.rs`：新命令 `pin_menu_action`、`desktop_menu`、`desktop_menu_shown`、`close_desktop_menu`、`take_open_request`、`copy_capture`。

## 每个菜单项的其他入口

| 菜单项 | 其他入口 |
|---|---|
| 翻转、旋转 | 钉图上按 H / V / R / Shift+R |
| 原始大小 | 滚轮缩放到 100% |
| 透明度 | Ctrl+滚轮 |
| 锁定位置与大小 | 只有菜单（与原生菜单相同） |
| 收藏到… | 主窗口截图历史的“收藏”按钮 |
| 复制（钉图） | 截图历史的“复制”按钮（新增） |
| 显示这张图 | 钉图上的小圆锁 |
| 存回参考组 | 主窗口“参考组”面板的保存 |
| 在 Kinshoko 中打开 | 主窗口里浏览到这张图 / 打开截图历史 |
| 加入参考组 | 主窗口“参考组”面板保存桌面钉图（整组） |
| 贴边隐藏 | F4（可改）；托盘菜单 |
| 关闭钉图 | 钉图上按 Esc；Alt+F4 |
| 截图历史：钉住 / 复制 / 收藏到… / 删除 | 条目上的“钉住”“复制”“收藏”按钮与 × |
