# 安装说明

## 安装

1. 下载 `Kinshoko_<版本>_x64-setup.exe`，双击运行。
2. 安装包只装到当前用户（`%LOCALAPPDATA%\Kinshoko`），**不需要管理员权限**，也不会弹出管理员确认。
3. 电脑上没有 Microsoft Edge WebView2 运行时时，安装包会联网下载并安装它（Windows 11 自带，一般不需要）。

## 为什么会出现“Windows 已保护你的电脑”

Kinshoko 暂时没有购买代码签名证书，Windows SmartScreen 不认识这个安装包，第一次运行时会显示蓝色的“Windows 已保护你的电脑”。这只说明安装包没有商业签名，不代表检测到了病毒。

确认安装包是从 Kinshoko 的 GitHub Releases 页面下载的之后：

1. 点“更多信息”。
2. 点“仍要运行”。

之后的自动更新由 Kinshoko 自己校验更新包的签名（与安装包里的公钥配对），签名不对的更新不会安装。

## 自动更新

Kinshoko 每次运行第一次打开主窗口时检查一次新版本；有新版本时主窗口底部会提示，点“安装并重启”即可。也可以在“设置 → 更新”里手动检查。更新过程中 Kinshoko 会退出，安装完成后自动重新打开，钉图位置会保留。

## 卸载

在“设置 → 应用 → 已安装的应用”里找到 Kinshoko 卸载。资料库、设置、截图历史与模型不会随卸载删除。

## 反馈问题时附上诊断信息

“设置 → 诊断 → 显示诊断信息／存成文件…”生成的诊断信息只有系统版本、处理器、内存、显卡、WebView2 版本、显示器型号与色彩模式（SDR、自动色彩管理、HDR）和显示器配置文件的名称，**不含文件名、路径与图片**，可以直接贴到问题反馈里。

“记录使用日志”默认关闭；打开后只在本机记下做了哪类操作与次数，不会自动上传，由你决定是否导出给开发者。
