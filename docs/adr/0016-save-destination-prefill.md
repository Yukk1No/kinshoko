# 保存入口按动作的来处预填位置，不设跨入口的默认资料库

[ADR 0008](0008-no-current-library-for-the-artist.md) 去掉了画师眼里的“当前资料库”，但前端仍用窗口打开的资料库（后端 `last_opened`）给导入、截图收藏、新建榜单资料库这些入口兜底（#417、#423）。画师大多数时候在「全部图片」里浏览，浏览范围给不出资料库；存参考组时没收藏过的截图逐张都要选图库，反馈很繁琐。

决定：每个入口按动作的确定性选依据，不设一条通用顺序，也不设跨入口共用的默认资料库。

- **动作本身指了位置**（拖到侧栏某个文件夹上；在某个文件夹、某个资料库的全部或未归类里拖入、粘贴、从菜单导入）：用这个位置，资料库的全部按未归类。
- **随手收藏**，与主窗口在看什么无关（钉图菜单、截图历史的「收藏」，存参考组时没收藏过的截图）：用截图收藏上次亲手选的保存目标；直接收藏，不弹对话框，完成提示写明存到哪里并可当场换位置；右键菜单另有「收藏到…」。存参考组时只收藏进一个可用资料库的截图仍预选那个库。
- **在对话框里有意识地选**，各入口各记各的：
  - 在「全部图片」里导入：导入上次亲手选的保存目标。
  - 复制到…：复制上次亲手选的保存目标，跳过图片所在的资料库。
  - 新建榜单资料库的位置：已有榜单订阅所在资料库的旁边 → 上次新建资料库的位置 → 登记最早的资料库旁边。
  - 订阅选已有资料库：该订阅已有的资料库。
  - 新建图库的存放位置：和已有的图库放在一起（上次新建资料库的位置 → 登记最早的资料库旁边）→ 系统的「图片」文件夹；都取不到时留空。
- 以上每条取不到时，落到**登记最早的可用资料库的未归类**（复制到…取另一个资料库）；一个可用资料库都没有时留空，由画师选。
- **回收站**和**墙上操作**不需要缺省：非「全部图片」的浏览范围都带着资料库，墙上每张卡片都带着所属资料库，导入回执带着自己的保存目标。
- **回收站里不能发起新的导入**：导入按钮的三个来源和图片墙右键的导入项（含从剪贴板导入）禁用，`Ctrl O`、`Ctrl V` 没有反应，拖入时不提示、松开后只发一条“回收站内无法导入”的通知。接着之前导入的操作不受影响：导入任务、结果卡重试和重新导入照常可用；重新导入走到预填时，仍预填这个资料库的未归类，可在对话框里改。

“上次亲手选的”只在画师于对话框里选定、或在完成提示里换了位置并确认时更新；动作本身指出的位置只用于那一次，不写进记忆。记忆按入口分开存在本设备的 `device.json`。记住的资料库暂时不可用（移动盘没插、读不到）时保留记录、本次落到兜底，资料库回来后恢复；取消登记该资料库时清掉；记住的文件夹已删除时落到那个资料库的未归类。

## Considered Options

- **一律要求明确选择**：没有新概念，但「全部图片」下每次导入、每张截图都要选，正是被反馈繁琐的地方。
- **一份跨入口共用的默认保存目标**：截图多是随手的参考，导入多是整理过的成批图片，两者想去的地方常不同；共用一份会让一边总要改，也容易被当成新的“当前资料库”。
- **所有入口一条通用顺序**（界面位置 → 上次 → 兜底）：截图收藏发生在画画时，跟着主窗口停在哪个文件夹走反而猜错。
- **沿用后端 `last_opened`**：它在注册、打开、新建资料库时变化，画师看不到也控制不了，等于把“当前资料库”从后门请回来。
- **记忆存在前端 localStorage**：主窗口与钉图窗口各存一份，也不跟随便携数据目录（[ADR 0009](0009-portable-data-root.md)）。
- **在回收站里也能导入，存到那个资料库的未归类**：画师看着回收站，新图却不出现在眼前，存到哪里也不直观。回收站里本来也不会有发起导入的需要。
- **最后一层兜底取图片最多的资料库**：多半是主力库，但随存图变化，不好预期。

## Consequences

- 预填只决定往哪里存，不影响浏览范围、详情面板和整理对象，文案里不出现“当前”“默认图库”。
- 前端不再持有窗口打开的资料库（#426）。`last_opened` 不留给前端，只留给后端决定启动时先把可写句柄给谁；`current_library` 命令仍在，前端只用它触发启动时的打开、不看返回值，e2e 用它核对后端状态。
- 截图收藏可能不经对话框就写进资料库，完成提示必须写明存到了哪里，并能直接换位置。

## 修订：「复制到…」入口已去掉（#425，2026-11-05）

单图详情统一成普通面板时，来源整理特有的「复制到…」随之去掉，它的命令和底层复制代码也一并删除，暂时没有跨资料库复制的入口，有需求时再加回来。上面关于它的预填规则因此没有落点；加回入口时仍按这些规则预填。
