# 应用级个人近似规则与旧库判断迁移

规格 #78 让个人近似规则跨资料库共用。规则由应用保存，引用 ADR-0006 的统一标签身份；没有外部对应的标签也能参加。逐图标签与人工整理继续由各资料库独立保存，近似查找只展开可见的任一条件，不合并标签。此决定自 #78 增量起替代 ADR-0003 Consequences 最后一项中个人规则“按库内标签记录、随资料库保存”的归属；ADR-0003 与前置验收原文保持不变。

显式个人判断优先于内置表。内置表更新不覆盖判断。“只这次”仅保留在当前查找条件，“以后都不展开”与“＋”保存长期判断。程序设置管理这些规则；设置备份必须保存完整判断以及旧库来源的确认、忽略和删除记忆。内容迁移不携带或替换个人规则。

旧库规则只作为迁移来源读取，不反向改写提供方。来源首次对应到两个统一身份时保存来源事实。相同判断可以自动沿用；相反判断必须显示来源并明确选择“相近”“不相近”或“不采用旧规则”，不得由打开或导入顺序决定。尚未选择且没有显式全局判断时，暂不展开该对；这不是保存了“不相近”。选择“不采用旧规则”后恢复内置行为。已有显式全局判断保持优先，新来源不得覆盖它。删除规则保留确认记忆，重启或重开旧库不得使规则复活。

## Considered Options

- 保留每库规则：同一次跨库查找会有相反判断，无法表达一个工作区条件。
- 最后打开的库覆盖前库：结果依赖登记顺序，删除规则后也容易复活。
- 将相近标签合并：会改变逐图人工整理的粒度，无法无损撤销。
