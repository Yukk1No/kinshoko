# 参考组独立于资料库保存

为复用来自多个资料库的局部参考，参考组独立于资料库保存，成员引用来源图并保存各自的裁切与布局，资料库中的图片及元数据仍归资料库所有。普通参考组保存引用，需要脱离原库使用或迁移时另生成携带原图的参考组包，避免每次保存参考组都复制素材。库合并后仅在用户确认时重连现有参考组并保存重连前备份；按资料库组织备份时纳入关联参考组，不改变其独立保存的归属。

## 修订：参考组自带截图（#270，2026-10-24）

只在一次绘画里用、用完就扔的截图，收藏进资料库会弄乱浏览和瀑布流，不收藏又存不进参考组。因此参考组成员也可以是参考组自带的截图：截图文件复制到这个参考组自己的存储里，成员直接引用它，不进任何资料库，也不出现在浏览、查找和以图搜图里。取舍是参考组不再只保存引用，要负责保管这些截图文件：没有成员再用某张自带截图时（移除成员、删除参考组、收藏后成员改为引用资料库中的参考图）随之删除；参考组包导出时一并带上，导入时还原；本地备份快照也带上这些截图，恢复时还原并在往返检查中核对。自带截图没有内容分级，安全模式下与截图钉图一样照常显示。只引用资料库的参考组文件格式不变。
