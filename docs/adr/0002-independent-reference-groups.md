# 参考组独立于资料库保存

为复用来自多个资料库的局部参考，参考组独立于资料库保存，成员引用来源图并保存各自的裁切与布局，资料库中的图片及元数据仍归资料库所有。普通参考组保存引用，需要脱离原库使用或迁移时另生成携带原图的参考组包，避免每次保存参考组都复制素材。库合并后仅在用户确认时重连现有参考组并保存重连前备份；按资料库组织备份时纳入关联参考组，不改变其独立保存的归属。

## 修订：参考组自带截图（#270，2026-10-24）

只在一次绘画里用、用完就扔的截图，收藏进资料库会弄乱浏览和瀑布流，不收藏又存不进参考组。因此参考组成员也可以是参考组自带的截图：截图文件复制到这个参考组自己的存储里，成员直接引用它，不进任何资料库，也不出现在浏览、查找和以图搜图里。取舍是参考组不再只保存引用，要负责保管这些截图文件：没有成员再用某张自带截图时（移除成员、删除参考组、收藏后成员改为引用资料库中的参考图）随之删除。截图历史里的那张截图记得由它而来的自带截图成员，所以无论从钉图菜单还是截图历史收藏它，即使钉图早已关掉、截图进了几个参考组，这些成员都改为引用收藏成的参考图；截图历史丢弃这张截图时这层关联随之消失，参考组那份不受影响，再次打开参考组时重新建立。参考组包导出时一并带上，导入时还原；本地备份快照也带上这些截图，恢复时还原并在往返检查中核对。自带截图没有内容分级，安全模式下与截图钉图一样照常显示。只引用资料库的参考组文件格式不变。

## 修订：参考组就是桌面（#588，2026-11-14）

画师反馈参考组动手太多、要记的事太多：桌面钉图和参考组是两份数据，存要起名、选截图去处，挪过钉图要记得“更新参考组”，换一组要一张张关掉再摆出，关掉钉图也不等于移出成员。因此参考组从“另存的快照”改为桌面本身：桌面上始终摆着一个参考组（可以是空的），桌面钉图就是它的成员，钉住、移动、缩放、翻转、关掉都直接写进这个参考组；画师在参考组之间整桌切换，原来那一桌原样留着；值得留的收进归档，取出后改的是原件。一次只摆一个参考组，合并两组改用“并入”。

取舍：失去了快照对参考组的保护（摆到桌面上随手一挪就改了它）和多组叠放在桌面上的用法；换来不用保存、不用起名、能整桌切换，画师要做的决定从七个减到三个（切换、新建、归档），而且都不是必须做的。

透明度和锁定改为随参考组成员保存，修订对齐记录 Q71（“透明度和置顶、锁定一样属于桌面使用状态”）：桌面就是参考组之后，不存的话切走再切回就丢了。参考组包不带这两项。

“在不在切换列表里”不写进参考组文件，只记在桌面状态里，不在列表里的就是归档。这样现有参考组文件零迁移（全部算作归档），备份、参考组包与永久删除预览仍按文件工作，不用跟着改。第一版不自动丢弃未归档的参考组，只有没有成员且没有名称的参考组会自己消失。
