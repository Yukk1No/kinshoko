# 没有明确依据的保存入口用本设备记住的默认保存目标预填

[ADR 0008](0008-no-current-library-for-the-artist.md) 去掉了画师眼里的“当前资料库”，但前端仍用窗口打开的资料库（后端 `last_opened`）给导入、截图收藏、新建榜单资料库这些入口兜底（#417、#423）。画师大多数时候在「全部图片」里浏览，浏览范围给不出资料库；而存参考组时没收藏过的截图逐张都要选图库，反馈很繁琐。决定：引入**默认保存目标**——画师最近一次确认的保存目标（资料库加文件夹），存在本设备的 `device.json`，确认导入、收藏、复制时更新；浏览、整理、切换浏览范围、存参考组时逐张改去处都不更新它。

需要保存位置的入口按同一条顺序预填，取第一个可用的：

1. 浏览范围是某个文件夹时，那个文件夹；是某个资料库的全部或未归类时，那个资料库的未归类。
2. 默认保存目标。
3. 只有一个可用资料库时，那个资料库的未归类。
4. 都没有就留空，由画师选。

各入口：

- **导入**（菜单、拖入、粘贴）：照上面的顺序预填，计划对话框照常出现。
- **截图收藏**（截图历史、钉图菜单）：预填可用时直接收藏，完成提示里可以换位置；右键菜单另有「收藏到…」。预填为空时照旧弹出对话框。
- **存参考组**：只收藏进一个可用资料库的截图预选那个库，其余截图按上面的顺序预选。
- **新建榜单资料库**：建在默认保存目标所在资料库的根目录旁；没有就建在登记最早的可用资料库旁；一个可用资料库都没有时由画师选位置。不看浏览范围。订阅对话框默认选中的已有资料库：已有订阅的库，其次默认保存目标的库，其次第一个可用的库。
- **回收站**和**墙上操作**不需要缺省：非「全部图片」的浏览范围都带着资料库，墙上每张卡片都带着所属资料库，导入回执带着自己的保存目标。

默认保存目标所在的资料库暂时不可用（移动盘没插、读不到）时保留记录、按顺序往下取，资料库回来后恢复；取消登记该资料库时清掉记录；记住的文件夹已删除时退回未归类。

## Considered Options

- **一律要求明确选择**：没有新概念，但「全部图片」下每次导入、每张截图都要选，正是被反馈繁琐的地方。
- **跟随浏览范围**：画师多数时候在「全部图片」，只覆盖少数情况；保留为第一优先，因为画师正在看某个文件夹时往那里存最符合预期。
- **沿用后端 `last_opened`**：它在注册、打开、新建资料库时变化，画师看不到也控制不了，等于把“当前资料库”从后门请回来。
- **存在前端 localStorage**：主窗口与钉图窗口各存一份，也不跟随便携数据目录（[ADR 0009](0009-portable-data-root.md)）。

## Consequences

- 默认保存目标不是“当前资料库”：它不影响浏览范围、详情面板和整理对象，文案里不出现“当前”。以后若想让它决定别的事，先重开本 ADR 和 ADR 0008。
- 前端不再读窗口打开的资料库来决定保存位置；`last_opened` 是否还需要留给前端，留到 #417 最后一步决定。
- 截图收藏可能不经对话框就写进资料库，完成提示必须写明存到了哪里，并能直接换位置。
