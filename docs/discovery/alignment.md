# 领域对齐记录

记录日期：2026-10-01。本文记录访谈中的共识与未决问题；当前尚未形成完整产品规格。

## 第一轮已确认

- **首个验收对象**：首位画师用户的 Windows 单人绘画工作流。
- **产品流程边界**：保存参考图 → 整理与检索 → 选择整图或局部 → 在绘画桌面使用。
- **最主要的痛点**：在自己的参考图库中找到需要的参考耗时最多，最妨碍绘画。
- **代表场景**：查找某种发色，或短发、长发、齐刘海、中分等发型；通过点击分类好的标签或输入文字找图，再截取需要的局部钉在桌面上。

以上首个验收对象用于验证阶段，未决定未来其他平台或使用群体的范围。
