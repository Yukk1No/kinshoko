# 初始设想

记录日期：2026-10-01。来源：项目发起者与画师讨论后的输入。

以下内容是领域访谈的起点。发起者明确表示“目前仅作参考”；这些设想尚未成为正式需求或实现决策。

1. 项目暂定名为 **Kinshoko**，灵感来自 Re:ゼロ 的“禁书库”；日语读音、罗马字和同名软件情况需要核实。
2. 希望覆盖二次元画师存取、使用参考图的全流程；“全流程”的具体起点、终点与任务边界需要对齐。
3. 项目数据应兼容多种存储方式，包括本地和远端；原图、元数据、缓存与同步是否属于同一要求需要讨论。
4. 需要读取、导入 Eagle 现有数据；直接访问原库与迁移到新库的边界需要讨论。
5. 图片应尽可能清晰地展示；需要根据实际屏幕、缩放比例和绘画使用场景确定验收标准。
6. 绘画参考包括整图和图片局部；希望将聚焦局部的参考悬浮并置顶于桌面，具体交互与保存行为需要对齐。

已有调研见 [anime-library-research.md](../research/anime-library-research.md)。报告中的源码判断和候选建议保留其原有验证范围，不能当作本产品的正式规格。
