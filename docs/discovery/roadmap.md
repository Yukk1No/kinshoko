# Roadmap 方向

2026-10-01。本文记录已确认的能力方向；不是已排期的版本计划或实现规格。

| 方向 | 已确认的目标 | 尚未确定 |
|---|---|---|
| 本地绘画参考闭环 | Windows 单人使用；复用开源识别能力提供自动标签建议，允许人工修正；标签和中文别名组合检索；关联原图的局部参考视图；Eagle 导入后独立管理 | 首个实用版本的完整范围、模型选择与验收指标 |
| 保存与复用参考组 | 多张图中的局部参考可组成一组保存，以后整体复用；保留各视图与来源参考图的关系 | 是否恢复布局、尺寸、缩放与置顶窗口状态 |
| 备份与恢复 | 收集的素材在设备损坏后仍能恢复；能力必须进入 roadmap | 保护数据范围、应用内流程、目标存储、历史保留与交付阶段 |
| 持续多设备同步 | 设备间持续传递图库的新增与修改；该能力必须进入 roadmap | 设备范围、双方编辑与离线行为、删除传播、冲突与同步时机 |

一次性换机恢复属于备份与恢复，不作为持续同步的完成条件。

发起者提出优先免费方案或开放存储接口的方向。当前还未决定把哪些责任交给 Kinshoko，哪些配置或存储资源由用户提供。

讨论中的建议是：由应用组织备份、恢复与同步流程，用户选择存储目标；通过可替换的接入方式使用本地目录或用户自有存储。该建议尚待确认，未选定具体工具或协议。
