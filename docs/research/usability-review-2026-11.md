# 易用性与视觉审查（2026-11）

按维护者转来的 11 条清单（第 6 条颜色只作方向）审查 `main @ 8e5daec2`。三路并行：主链路交互、界面文案、视觉样式。每条结论都在当前代码上复核过；旧代码里有、现在已经修掉的不再列出。

## 现状

设计系统已经覆盖了清单的大半：字号只有 16 / 13 / 12 三档，单屏最多 3 档；没有斜体、全大写和中点分隔；圆角同心；能撤销的操作不先确认；令牌之外没有写死的颜色；红色实底只出现在确认对话框里。问题集中在四处：

1. 新手主链路有三个断点：空图库没有动作，导入完不知道结果在哪，自动标签模型的下载提示被关掉后再也找不回。
2. 数字：四份字节换算各用各的进制，几 GB 的备份显示成“8123.4 MB”；计数没有千分位；同一个置信度，设置里写 0.80，标签上写 87%。
3. 文案：“资料库 / 登记 / 打标 / 外部对应 / 统一标签目录”这类内部词还在错误信息和设置里；同一动作有几种叫法（恢复 / 还原，永久删除 / 彻底删除，改名 / 重命名）；欢迎页、导入对话框和设置里还留着解释句。
4. 样式：减少动画只管住了用令牌的时长，写死的毫秒数和只写媒体查询的规则漏网；有几处文字用 `opacity` 调淡，对比度掉到 4.5:1 以下；导航项、设置卡等不浮起的面用了阴影；还有散落的写死动效时长，以及已经失效的让位选择器（`.selbar-host`）。

## 本轮改动

分三个分支，互不重叠：

| 分支 | 内容 |
| --- | --- |
| `claude/product-usability-design-review-1f0bb0` | 主链路：空图库给“导入图片 / 导入文件夹”按钮，查找没有结果时给“清除条件”；导入顺利结束的轻提示带“打开”，直接跳到导入的图库与文件夹；正在导入时拖进来会给提示，不再没有反应；自动标签需要下载、出错或不可用时，右下角留一个静止图标，点开就是设置；带“撤销”的轻提示停留 8 秒（原来 5 秒）；空状态文字改用 `ink-2`（原来用透明度 0.7 调淡）。 |
| `claude/number-formatting` | 统一的字节、百分比、计数和日期格式；置信度设置改用百分比。 |
| `claude/style-drift-fixes` | 减少动画总开关；调淡文字的透明度改成 `ink-2`；去掉不浮起的面上的阴影；写死的动效时长改用令牌（新增 `--t-pop`）；删掉重复的旧拖入提示样式；快捷键改回正文字体；图片悬停描边改成 1 px 细线；失效的让位选择器改指 `.selbar-float`。 |

## 待定：较大的改动

这些改起来不止换几个字，需要先定方向：

1. **删除文件夹、删除标签分组、删除参考组还在先确认。** 图片都不会删，按“能撤销就不确认”应改成直接执行加“撤销”。要做撤销，后端得能恢复文件夹层级和归属。
2. **按钮、菜单、设置项名称用省略号截断。** 规则是宁可换行、改文案，也不截断。v1.1 做英文界面时会立刻碰到：英文更长，`.k-label` 一律不换行。
3. **夜间的警告色、强调色与人工标签色是同一个金色。** 同屏分不清“选中”和“警告”。你说颜色不用太在意，所以没动，只记在这里。
4. **错误原文直接拼进界面（`String(e)`）还有十来处。** 应该统一走错误码，原文只进运行日志。
5. **新手看不到“点标签查找”这条路。** 新图库没有任何标签分组，标签栏只有一行提示。可以考虑首次使用时按词表预置几个分组（发色、瞳色、服装、姿势）。
6. **旧样式层还在生效。** `base.css` 的全局 `button` 样式、标签分组栏和查找浮层是两套外观；编辑分组对话框有三层盒子套盒子。宜逐步迁到新组件。
7. **焦点样式有六种写法。** 输入框的焦点还带一圈 4 px 光晕。
