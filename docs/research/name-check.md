# Kinshoko 名称核查

核查日期：2026-10-01。项目名称仍是暂定名。

## 读音与拼写

「禁書庫」读作「きんしょこ」。Bandai 的官方 Re:ゼロ 联名卡牌标注了这个读音：[UNION ARENA「禁書庫」](https://www.unionarena-tcg.com/jp/cardlist/detail_iframe.php?card_no=UA40BT%2FREZ-1-094)。动画官网也使用这个词指贝阿特丽丝所在的书库：[Re:ゼロ 第二季剧情页](https://re-zero-anime.jp/tv/story/tv2.html)。

按平文式罗马字，き＝ki、ん＝n、しょ＝sho、こ＝ko，合为 **kinshoko**，无长音符号。对应关系见日本国土交通省文档中的罗马字表，PDF 第 20 页：[罗马字表](https://www.mlit.go.jp/common/001258069.pdf)。
