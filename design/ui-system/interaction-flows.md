# 操作流程

正式程序里几处操作的定型做法。具体用词见 [interface-terms.md](interface-terms.md)。

1. 图库切换：标题行“图库 ＋”，没有“当前图库”（#113，ADR-0008）。
2. 侧栏：每个图库一组目录，只展开所选图库，拖动悬停展开（方案 D）；未连接的图库名称变淡、带警示点，同一行末尾是“重新连接”，原因在悬停提示里；回收站跟随所选图库，与子文件夹开关固定在底部。回收站不写图库名，图库名在悬停提示与无障碍名称里。
3. 来源：只有在多个图库的卡片有来源按钮，显示“2 处”；只在一个图库的图没有按钮（#221）；详情面板用分段切换来源，标签、分级、文件夹、备注随来源切换。
4. 多选：浮动操作条（移到文件夹、移出此文件夹、移到回收站）。
5. 导入：顶栏“导入”按钮打开菜单选来源（图片 Ctrl O、文件夹、从 Eagle 导入、导入任务）→ 对话框选图库和文件夹（Eagle 额外问删过的图）→ 右下进度卡 → 结果卡（重试失败、查看新增）。拖入窗口照常可用，菜单里不写提示行。
6. 提示：不用常驻红字横幅，用轻提示（自动消失）。能撤销的操作不先确认，做完给带“撤销”的轻提示；只有不可撤销的操作保留确认对话框。浏览结果变化时自动重读，不提示。
7. 设置：八个分页（通用、快捷键、标签、自动标签、备份、安全、更新、诊断），每项一行：图标 + 名称 + 右侧控件；不写描述行，名称说不清时的补充放进悬停提示，当前状态（版本、进度、位置）用小字放在控件左边；改动即生效。
8. 截图读数：Dock 只显示“宽 × 高”加字标的星，“原始像素”“屏幕像素”只在悬停提示里。
9. 图集（#418）：同一图集叠成一摞，占一格，左上角是张数按钮（GalleryVerticalEnd 图标，与来源按钮的 Layers 分开）。单击选中整摞；再单击、双击、回车或点张数，墙在原位让出一条托盘（缩在墙的边距里、圆角），各页按页序排成齐行（行高以列宽为准，排不下时整行缩小到刚好排满，最后一行不撑满），不新建层级、不跳转；托盘里的页不带张数和页码。托盘里单击选一页，Ctrl / Shift 单击或点页角的勾多选，焦点在托盘里时 Ctrl+A 只选这一摞；双击一页进查看器。Esc 先取消页的选择，再按一次关托盘；点托盘以外关托盘（点到别的格子时同时选中它，这一格留在屏幕原处），点详情面板不关，点托盘背景只取消页的选择。从一摞打开查看器（右键“打开”）时看它的第 1 页；查看器里左右先在这一摞里翻，翻完接着墙上的下一格，往回同理；序号和张数只算这次浏览能显示的页（符合查找、不被安全模式藏起）。选中整摞时，移到回收站、永久删除、恢复、移到文件夹（含拖到文件夹上）、内容分级和详情面板里的整理作用于它的全部页，菜单的“移到回收站（n 张）”、多选悬浮栏和删除后的提示写明张数；钉住、钉住局部、复制图片和加入参考组只取封面，要别的页先打开托盘。墙的右键菜单里有“叠放图集”开关，默认开。
