# 主窗口的质感

主窗口桌面、纸、槽、顶栏与侧栏的质感规则。为什么这样定、各轮的截图与对比度在原型 `design/prototype/main-window-material/` 的 [README](../prototype/main-window-material/README.md)。

令牌的值在 `src/styles/tokens.css`。下面的表只写意思；两边对不上时以 `tokens.css` 为准，并在同一个 PR 里改这份文件。

## 桌面与纸

窗口的底是一张米黄的桌面，侧栏、主区、详情面板是放在桌面上的三张纸。

- **桌面**：`--desk` = `--rail`。图标轨直接放在桌面上，没有自己的底色，右边线透明。
- **纸**：圆角 `--r`；边与投影 `--sheet-lift`（半像素细线、小投影、往下偏的远投影）；上沿一线亮边 `--sheet-top`，画在纸的最上一层（`::before`，不接收指针），免得被纸里内容的底色盖住。
- **主区那张纸**：底色 `--sheet-main`（日间 `--surface`，夜间 `--bg`），顶栏与它同色。图片墙仍是中性灰 `--wall`，在这张纸里面，四周不画投影。
- **间距**：纸与纸、纸与窗口边之间露出 8 px 桌面（`--sheet-gap`）。`app-body` 的内边距是上 8、右 8、下 8、左 0（左边贴着图标轨）。
- **宽度**：侧栏 256 = 纸 248 + 右边 8 px 桌面；详情面板 320 = 左边 8 px 桌面 + 纸 312。两栏收起时连同那 8 px 一起收掉，不留空缝。
- 窄窗口里侧栏与详情面板一起让到 200（`src/shell/paneFit.ts`）。
- **贴着图片墙的面板不用投影**：投影只落在桌面上。

## 槽：输入类控件

查找框、`.k-input`、`.k-select`、详情面板的备注框都是纸上压下去的一道槽。

| 令牌 | 意思 |
| --- | --- |
| `--well-floor` | 槽底：日间 `--surface`，夜间 `--sunken` |
| `--well-inset` | 槽口：上沿一线暗、内阴影、半像素一圈线，下沿一线亮 |
| `--well-inset-hover` | 悬停：同上，那一圈线深一档 |
| `--well-focus` | 输入时：那一圈线变实（日间墨紫 55%，夜间奶油 50%，1 px），外面 3 px 很淡的晕（8%） |

- 日间槽底不变暗，深度只画在槽口（字的对比度不能降）；夜间槽底变暗，亮字对比度反而升高。
- **输入类控件获得焦点时不画强调色的焦点环**，换成 `--well-focus`；查找框开头的放大镜同时从 `--ink-3` 变成 `--ink`。适用于查找框、`.k-input`、备注框；`.k-select` 是按钮一样的触发器，仍按焦点环规则。这是 [tokens.md](tokens.md)“焦点环”的例外。
- 填错的输入框（`[data-invalid]`、`[aria-invalid="true"]`）仍是红线，不用 `--well-focus`。
- 分段控件的槽同族：槽 `--well-inset`，选中的一段是 `--btn-face` 配 `--btn-lift`。

## 顶栏

顶栏在任何宽度下都只有一行：**查找框、导入、详情面板开关、窗口控件**。顶栏下沿一线 `--line`，下面没有分组条。

- **查找框**：开头 16 px 放大镜（左 12 px，文字从 36 px 起），最宽 640 px。尾部从左到右依次是：张数（只在有查找条件时）、标签分组图标按钮、精确查找开关。
- **张数**：没有查找条件时不显示（它等于侧栏选中那一行的数字）；有条件时在查找框里，12 px `--ink-2`，等宽数字。主区窄时也不单独收起它。
- **标签分组**：32 × 32、圆角 `--r-s` 的图标按钮，与精确查找开关同样大小、同样的悬停与按下（悬停 `--hover` 底、按下 0.94）。名称“标签分组”只在悬停提示与无障碍名称里。
- **分组面板**：挂在查找框正下方，与查找框同宽、不窄于 420 px，外形同 `.k-popup`。所有分组的标签一次摆出来，可以跨分组连选，面板不关；“任一成员”在指针移到分组上时出现在分组名右边；“编辑分组”是面板底部的一行，打开现有的“编辑分组”对话框。选了的标签就是查找框里真的条件。
- **条件块**：平时只有名称；指针移上去、键盘走到或它的菜单开着时，相近（＋、×）、排除、去掉几个按钮才在块里展开。收起的按钮不占宽度但仍可聚焦。排除的条件靠“不要”与删除线认出来。
- **条件块的收纳**：`fitChips.ts` 算可用宽度时要扣掉放大镜、张数、分组按钮与开关。

## 侧栏的文件夹视图

### 行

选中用平的“指示条”，不用凸起的纸片：纸片放在“全部图片”那一行时像一颗按钮。对照图在 `design/prototype/main-window-material/shots/rows-compare-*.webp`。

- **悬停**：滑动的高亮块，平的 `--hover`，没有边。
- **按下**：不缩；底色深一档 `--row-press`（选中的行是它的底，别的行是悬停块）。
- **选中**：平的 `--hover` 底画在行的 `::before` 上，左边一根 3 × 14 的强调色短条（`--accent`，圆角 2，上下各留 8）画在 `::after` 上。名字是 `--ink`、字重 500；图标 `--accent-strong`；张数不变（`--ink-2`）。“全部图片”、图库行、文件夹行都一样。
- **短条滑动**：换一行时短条从旧的一行滑过来（弹簧约 0.36 秒），整个侧栏一根：“全部图片”、图库行、各图库的文件夹之间都滑。选中的底不滑，直接出现。
- **图库之间**空 10 px，不画分界线（见 [window-frame-and-sidebar.md](window-frame-and-sidebar.md)“三种行”）。
- **展开箭头**：换图标时新图标从另一个的角度转过来（`--t-slow`、`--spring`）；目录展开时各行依次落下（每行晚 18 ms），收起时合上，目录留到收起播完再拿掉。

### 文件夹图标

- 只有线框，线宽 1.75，不填色、不加投影。
- **有子文件夹的**是两层的文件夹：展开时前面一页翻下来，折起时合上。后面的夹子被前面一页挡住的线用遮罩挖掉，所以放在悬停、选中、托盘任何底上都一样。
- **选中的那一行**：线框是 `--accent-strong`。
- **选中的在哪一支**：选中那一行往上的各层文件夹，线框是强调色 45% 混 `--ink-3`，不用线去连；分支折起时也一样。

### 子文件夹的层级

- **缩进**：每深一层整行（选中的底与短条、悬停的底一起）缩进 16 px，文字左内边距不变。
- **折痕**：每深一层，子文件夹那一块的左边有一道纸边 `--crease-edge`（一线暗、一线亮），往右 36 px 渐渐淡掉（`--crease`）。只有左边，不围成框，张数仍然对齐，不多占高度。选中的文件夹下面不染色。
- **折起**：点有子文件夹的文件夹图标（点的范围比图标大一圈，到行的左边与上下边）折起或展开；指针停在图标上时先变成点下去之后的样子，图标放大到 1.08，按下 0.92。键盘：← 折起、→ 展开。折起了哪些每个图库各记一份，记在本机（`localStorage`），重开程序还在；在折起的文件夹里新建子文件夹时它先展开。

### 拖动排顺序

这一节是定下来但还没做的样子，由 #636 实现，`--held-lift`、`--drop-edge` 届时加进 `tokens.css`。现在文件夹用浏览器的拖放，放到另一个文件夹上就移进去，排在最后。

- 文件夹拖动用指针事件；把图片从图片墙拖到文件夹上仍用浏览器的拖放。后端 `move_folder` 收“第几个”。

- **指针**：文件夹上是手指，拖着时是抓住的手。
- **拿起**：那一行跟着指针走，缩到 90%，挂在指针右边，边与投影 `--held-lift`；里面有子文件夹时下面垫一张。它的位置合上，悬停高亮隐去。
- **落点**：两行之间一道 2 px 的线，`--ink` 15%，从中间长出来，换位置时滑过去；拿起的那一行自己的位置不画。
- **让开**：线两边的行退开，最近的 6 px，往外每行是前一行的 0.7 倍、晚 24 ms 出发；弹簧约 0.28 秒，几乎不过冲。
- **放进文件夹**：在一行中段停 0.32 秒，这一行出现 `--drop-edge`（1.5 px 墨色线），松手放进去。
- **换层**：同一道缝属于两层时，默认留在拿起时所在的那一层；往左带一带到外面一层，线的左端跟着缩进。
- **取消**：Esc，或拖到侧栏外面松手，各行弹回，手里那张飞回原位。
- **键盘**：焦点在文件夹上时，Alt + ↑ ↓ 在同级里挪，Alt + → 放进上一个文件夹，Alt + ← 移到外面一层；结果读给读屏用户。
- **减少动态效果**：只留落点的线，行不让开、不弹，选中的短条不滑。
- 位移都用 `transform`，不动排版。

- 拖到上下边缘自动滚动；拖到折起的图库上约 0.6 秒自动展开（[window-frame-and-sidebar.md](window-frame-and-sidebar.md)）；可以拖进折起的分支。

## 详情面板没选图片时

开着详情面板、没有选中图片时，内容区上方居中一张用矢量画的抽象详情面板（`InspectorEmpty`）：一张图（远山、太阳）、两道名字线、三枚标签，宽 200 px；下面一句 12 px `--ink-2` 的提示。只用 `--sunken`、`--line`、`--line-2`、`--manual-soft`、`--accent-soft`，不动、不闪，免得像在加载。

## 这些令牌

都写成 `light-dark(日间, 夜间)`，只用墨紫、奶油、强调色、黑、白的透明度与已有令牌，不新增颜色。

| 令牌 | 用在哪里 |
| --- | --- |
| `--desk`、`--sheet-gap`、`--sheet-main`、`--sheet-lift`、`--sheet-top` | 桌面与纸 |
| `--well-floor`、`--well-inset`、`--well-inset-hover`、`--well-focus` | 槽 |
| `--row-press` | 侧栏的行按下 |
| `--crease`、`--crease-edge` | 子文件夹的折痕 |
| `--held-lift`、`--drop-edge` | 拖动排顺序（#636 加） |
