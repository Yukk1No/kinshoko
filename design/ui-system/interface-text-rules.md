# 界面文字规则

- 名称 2–4 字，描述不超过 20 字，不用术语。原则依据《Don't Make Me Think》与《写给大家看的设计书》：一眼能懂、少即是多、相关的放在一起。
- 界面用“图库”，代码与文档继续用领域词“资料库”（见 `GLOSSARY.md`）。
- v2：不用中点“·”分隔，两样信息并列时用间距、字重或颜色分开；不写解释性描述，名称说不清时先改名称，仍需补充的放进悬停提示；能撤销的操作不先确认，做完给带“撤销”的轻提示。
- 用词平实：用自然、日常的中文，语气清晰、平实，不刻意追求“生动”或“种草感”，也不过度拟人化。过程用中性词，如读取、生成、输入、输出、筛选、冲突。不用身体感强、网感重的动词，如吃（参考图/输入）、吐（结果/输出）、盯（功能/特性）、画面撞、筛（结果/图片）、喂、啃、喷。界面文字、原型、设计说明、PR 里的方案描述都按这条写。
- 逐条改写对照见 [copy-map.md](copy-map.md)。
