# 组件

## 组件库

负责人提供了几个候选库，要求“一切以美学设计和 user friendly 优先”，不强行使用。现在的用法：

| 库 | 用法 | 依据 |
| --- | --- | --- |
| [Base UI](https://mui.com/base-ui/) `@base-ui/react` · MIT | 交互基础层 | 无样式组件，覆盖菜单、右键菜单、下拉选择、可搜索选择、浮层、对话框、提醒对话框、标签页、开关、滑块、轻提示、提示、滚动区、分段切换。键盘与读屏行为由库负责，样式直接套本项目的令牌。 |
| [motion](https://motion.dev/) · MIT | 动效 | 驱动弹簧档位与布局过渡（悬停高亮、指示块滑动）。必须遵守减弱动效。 |
| [lucide-react](https://lucide.dev/) · ISC | 通用图标 | 图标轨 20 px、线宽 1.75；界面内 13–16 px。 |
| [Fluid Functionalism](https://github.com/mickadesign/fluid-functionalism) · MIT | 交互与动效规范 | 移植了无依赖的 `use-fluid-hover`（高亮滑到离指针最近的行，空隙里点击落到被高亮的行）与 `springs` 动效档位，从 `src/ui/motion.ts` 再导出，保留原版权声明。本项目只用 moderate 一档，在 `FluidList` 的悬停高亮上。原库的组件样式写在 Tailwind 类名里，不直接搬，用本项目令牌重写。 |
| [Arc Library](https://github.com/kuratlielia/arc-library) · MIT | 按钮与 Dock 的参照 | 开源部分提供 button、split-button、segmented-control 的写法与 snappy / smooth / morph 弹簧。Arc Pro 的 Dock 是付费组件，本项目按它公开的行为说明自己实现，不复制代码。 |
| beUI | 只参考动效写法 | 弹簧、模糊交叉淡入、布局过渡。官方仓库与许可证未能确认，不引入代码。 |
| [RareUI](https://github.com/Codewithswappy/RareUI) · MIT | 主界面不用 | 液态、玻璃、3D、WebGL 背景这类装饰会干扰画师用眼睛判断参考图的颜色。 |
| [Shaders](https://shaders.com) | 只用于短暂的“时刻” | 见下面“着色器特效”。 |

- 新增依赖只限 `@base-ui/react` 与 `motion`。
- 移植的 Fluid Functionalism 源码放在独立的 vendor 目录，文件头保留出处与许可证。
- 任何新库都要先在这张表里登记许可证与用途。

### 着色器特效

- 常驻界面（侧栏、顶栏、图片墙、查看器）与图片周围不用着色器：画师要靠眼睛判断参考图颜色，作画时也不能占显卡。
- 只能用在短暂的“时刻”：封印书的封印与释放演出、空状态、首次启动、导入完成。
- 演出结束或窗口隐藏就停止渲染。
- 减弱动效时给静态画面；没有 WebGPU 时退回 CSS 写法。
- 用到哪一处，要在对应工单里列明。

## 菜单

- 侧栏标题“图库 ＋”的菜单：打开图库…、新建图库…、管理图库。没有“当前图库”（ADR-0008）。
- 图库标题的 `⋯` 悬停时出现，和图库标题的右键菜单是同一组菜单项：新建文件夹、在资源管理器中打开、重新连接（未连接时）、分隔线、从列表移除。
- 图片右键菜单每项有图标和快捷键提示；危险项放在最下面，红字。
- 查看器、侧栏文件夹与回收站的右键菜单与图片右键菜单同一样式。
- 清空回收站走 `AlertDialog` 确认；删除文件夹不确认，轻提示带“撤销”。

## 来源按钮

- 只在属于两个以上图库的卡片右下角出现，写“N 处”。
- 只在一个图库的图没有这个按钮，选中后在详情面板里看所在图库。
- 按钮是卡片选项的兄弟元素；选项里不放可聚焦的子元素。

## 设置

- 每项一行：图标、名称、右侧控件。补充说明放在悬停提示里。
- 一组设置是 `--sunken` 托盘里的一张 `--surface` 卡，不写组名。
- 整组的说明放在卡片下方的托盘里。
- 行下方的内容是卡片底部的 `--bg` 内槽。
- 对话框起始高 480 px；切页时容器不动，只有放不下的长页才长高，最高 620 px。带搜索和列表的“标签”页停在最高。

## 对话框里会变高的内容

- `DialogHeight` 包住标题与底部按钮之间的内容。高度过渡时上下边缘对称移动。
- 超出 `max-height` 时这一段滚动，高度停在上限。
- `DialogSwap` 在换步骤时交替内容，`step` 的增减决定滑动方向。

## 分段控件

- 选中的一段由一个指示块标出（`.k-seg-thumb`，`--surface` 底、1 px `--line` 内线），不是每段各有底色。
- 指示块按选中那一段的位置和宽度摆，各段可以不等宽。
- 换一段时指示块滑过去（`--t-slow` 加弹簧，与开关的圆钮相同）。第一次出现和尺寸变化时直接到位。
- 还没有选中任何一段时不出现指示块。

## 详情面板的属性表

- 在文件名下面，“作者 / 角色 / 作品 / 分级”四行同级。
- 左列是类别名（12 px、600、`--ink-2`，不带图标），右列是内容。行距 10，列距 12。
- 前三行是一级标签（见下一节）；哪一类没有标签就不占行。
- 分级总在最后一行，是分段控件。指示块始终停在当前生效的那一档。
- 分级各档先按文字占宽，余下的平分。面板最窄 280 px 时，四档加星也放得下。
- 星标在模型给的那一档文字前（12 px，离文字 4）。分级是自动的时候，星跟文字同色。
- 画师改过分级之后，星留在原处、变成 `--ink-3`。悬停那一档时星亮回文字色，提示“改回自动”；点它就改回自动。
- 不写“自动分级：…”“已手动修正”这类说明行，也不另放“改回自动”按钮。
- 没有自动分级时，哪一档都不带星。

## 详情面板的标签

- 作者、角色、作品是一级标签，在属性表里各占一行。行首写类别，标签上不写“作者：”这类前缀；浮层与读屏名称仍写全名。
- 一级标签比一般标签大一号：28 高、13 px、左右内边距 10。
- “标签”区只放一般标签：26 高、8 圆角，只写名称。名称比面板宽时在标签里折行。
- 被排除的标签不分类别，都列在“标签”区的“已排除”下，写全名：无底细线、名称划掉。末尾是 20 px 的 `Undo2`“改回自动”，悬停它时划线先去掉。
- 按准不准分三档，日夜规则相同：
  - 人写的（人工、导入）和模型高档：`--tag-fill` 实心底。`--tag-fill` 日间同 `--surface-2`；夜间另取一个值，因为 `--surface-2` 在夜间面板上看不出来。
  - 模型中档和没有分数的模型标签：无底、1 px `--line-2` 细线框、`--ink-2` 字。
  - 低档：无底、1 px `--line-2` 虚线框（`outline`）、`--ink-2` 字。
- 档位只改颜色和线，不改字重和尺寸。人工和导入在标签上不做区分。
- 排列：人写的在前（你添加的、导入），模型标签按可信度从高到低。按出处分组时依次是“你添加的 / 导入 / 自动标签”。
- 星星代表“智能”，只出现在三处：“自动标签”分组标题前、浮层里打标模型那行前、属性表里模型给的那一档分级前。图标是 lucide `Sparkles`，与设置里自动标签页签同一个，跟文字同色。

## 详情面板的添加标签

- 只有一个输入框，前面是 16 px `Plus`。不另放按钮行，选几张时也不写说明句。
- 候选行回车或单击添加。
- 排除是高亮行行尾的 24 px `Ban` 按钮（替换张数，悬停时名称划掉）。Alt+回车、Ctrl+单击同样排除，与查找框一致。
- 选几张时，行尾多一个 `Undo2`“改回自动”；新建项末尾也有一个（按输入的名称）。键盘是 Shift+回车。
- 行尾按钮不可聚焦。悬停提示是动作名加快捷键，如“排除 Alt+Enter”“改回自动 Shift+Enter”。
- 没有同名标签时，最后一行是“新建“名称””。名称下一行选类别：一般 / 作者 / 角色 / 作品，选中的是 `--accent-soft` 底配 `--accent-strong` 字。类别只管这一次。
- 在名称前写“作者：”等同样指定类别，候选也只列这个类别。
- 加上的作者、角色、作品出现在上面的属性表里。

## 轻提示

- 可撤销，自动消失。不用常驻红字横幅。
- 一次性的结果与出错都走轻提示（导入结束、导入出错、备份没有完成），不另画卡片或横幅。
- 有事等画师处理的常驻提示也走轻提示（`usePersistentToast`）：不自动消失，关掉后设置里还有入口。
- 导入进度与导入前要回答的问题是右下角的任务卡，停在轻提示上方。

## 图标提示

- 写名称加快捷键。
- 一般提示与 Dock 提示外形相同：`--surface` 底、`--ink` 字、8 圆角、6 / 10 内边距、`--shadow-pop`，日夜跟随主题。

## 标签分组

- 入口是查找框尾部 32 × 32 的图标按钮。面板挂在查找框正下方，与它同宽，不窄于 420 px。
- 所有分组一次摆出来；“编辑分组”在面板底部。细节见 [main-window-material.md](main-window-material.md)“顶栏”。
- 面板外形同 `.k-popup`（见 [scales.md](scales.md)“半透明浮动面板”）。
- 面板里的标签块与查找框里的条件同样子：28 高、8 圆角、`--surface-2` 实心底。
- 选中的标签是 `--accent-soft` 底配 `--accent-strong` 字；排除的是无底细线加删除线；没有图的标签无底、淡字。
