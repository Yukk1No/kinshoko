# 界面用词表

写界面文字时，同一样东西、同一个操作只用一个词。下表按主题列出该用的词和不再用的词；没列到的按 [interface-text-rules.md](interface-text-rules.md) 写。#78 用引号规定原文的地方照原文，表里标了“#78 原文”。

## 图库

| 用 | 不用 | 说明 |
| --- | --- | --- |
| 图库 | 资料库 | 代码与文档继续用领域词“资料库”（见 `GLOSSARY.md`） |
| 打开图库；移除 | 登记已有资料库；取消登记；刷新登记 | 移除只断开，不删文件，悬停提示“文件不会删除” |
| 新建图库；图库名称 | 建立图库；建立资料库；资料库名称 | 对话框标题和按钮同一个动词 |
| 管理图库 | 资料库管理 | |
| 未连接；重新连接 | 暂时不可用；资料库已失效 | 原因放悬停提示 |
| Eagle 库 | Eagle 图库；Eagle 资料库 | Eagle 的库不叫“图库”，免得和本程序的图库混淆 |
