## 操作流程变化

1. 图库切换：原生下拉 + 折叠操作区 → 侧栏标题菜单（单选 + 打开/新建/管理）。
2. 侧栏：每个图库一组目录；未连接显示内联卡片和“重新连接”；回收站与子文件夹开关固定在底部。
3. 多来源：只有一张图在多个图库时才显示“2 处”；详情面板用分段切换来源，标签/分级/文件夹/备注随来源切换。
4. 多选：浮动操作条（放入、加标签、加入组、删除）。
5. 导入：顶栏“导入”→ 选择来源 → 对话框选图库和文件夹（Eagle 额外问删过的图）→ 右下进度卡 → 结果卡（重试失败、查看新增）。
6. 提示：常驻红字横幅 → 轻提示（可撤销、自动消失）。
7. 设置：七个分页（通用、快捷键、标签、备份、安全、更新、诊断），每项一行：图标 + 名称 + 一句描述 + 右侧控件。
