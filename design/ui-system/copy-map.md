## 操作流程变化

1. 图库切换：原生下拉 + 折叠操作区 → 侧栏标题菜单（单选 + 打开/新建/管理）→ 标题行“图库 ＋”，没有“当前图库”（#113，ADR-0008）。
2. 侧栏：每个图库一组目录（方案 D：只展开所选图库，拖动悬停展开）；未连接的图库名称变淡、带警示点，同一行末尾是“重新连接”，原因在悬停提示里（v2）；回收站跟随所选图库，与子文件夹开关固定在底部。
3. 来源：只有在多个图库的卡片有来源按钮，显示“2 处”；只在一个图库的图没有按钮（#221）；详情面板用分段切换来源，标签/分级/文件夹/备注随来源切换。
4. 多选：浮动操作条（移到文件夹、移出此文件夹、移到回收站）。
5. 导入：顶栏“导入”按钮打开菜单选来源（图片 Ctrl O、文件夹、从 Eagle 导入，v2 起不再是分体按钮）→ 对话框选图库和文件夹（Eagle 额外问删过的图）→ 右下进度卡 → 结果卡（重试失败、查看新增）。
6. 提示：常驻红字横幅 → 轻提示（可撤销、自动消失）。能撤销的操作不先确认，做完给带“撤销”的轻提示；只有不可撤销的操作保留确认对话框。
7. 设置：八个分页（通用、快捷键、标签、自动标签、备份、安全、更新、诊断），每项一行：图标 + 名称 + 右侧控件；v2 起不写描述行，名称说不清时的补充放进悬停提示，当前状态（版本、进度、位置）用小字放在控件左边；改动即生效。
