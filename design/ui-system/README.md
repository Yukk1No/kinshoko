# 界面系统

**状态：方向已认可 · 2026-10-10。** 负责人认可了视觉方向与改版预览（`preview/`）。正式前端尚未按此改版，实施归 #98。

本文件记录组件选型、品牌不变项、窗口框架、视觉与动效、文案规则。体验基线仍是认可原型 `prototype/reference-browser/`（固定提交 `bd8aea44`）及其 [设计说明](../../prototype/reference-browser/DESIGN-NOTES.md)；本文件只补正式程序需要、原型没有覆盖的部分。

## 组件库选型

负责人提供了五个候选库，要求“不用强行使用，一切以美学设计和 user friendly 优先”。核对结果如下（2026-10-10）：

| 库 | 角色 | 依据 |
| --- | --- | --- |
| [Base UI](https://mui.com/base-ui/) `@base-ui/react` 1.6.0 · MIT | **采用：交互基础层** | 37 个无样式组件，来自 Radix / Floating UI / MUI 团队，覆盖菜单、右键菜单、下拉选择、可搜索选择、浮层、对话框、提醒对话框、标签页、开关、滑块、轻提示、提示、滚动区、分段切换。键盘与读屏行为由库负责；不要求 Tailwind，直接套用本项目的设计令牌。 |
| [motion](https://motion.dev/) 14.1.0 · MIT | **采用：动效** | 驱动上面的弹簧档位与布局过渡（悬停高亮、指示块滑动）。必须遵守“减少动画”。 |
| [lucide-react](https://lucide.dev/) 1.52.0 · ISC | **沿用** | 原型已用的通用图标；图标轨 20 px / 线宽 1.75，界面内 13–16 px。 |
| [Fluid Functionalism](https://github.com/mickadesign/fluid-functionalism) · MIT | **采用：交互与动效规范** | 仓库为 MIT（Copyright (c) 2026 Micka Touillaud），底层同样支持 Base UI。移植其无依赖的 `use-fluid-hover`（高亮滑到离指针最近的行，空隙点击落到被高亮的行）与 `springs` 动效档位（fast 0.08 s / moderate 0.16 s / slow 0.24 s，退出用更快一档的补间）；保留原版权声明。组件样式写在 Tailwind 类名里，不直接搬组件，改用本项目令牌重写。原则同样采纳：动效只为传递信息；越大的东西动得越慢。 |
| [Arc Library](https://github.com/kuratlielia/arc-library) · MIT | **采用：按钮与 dock 的参照** | 开源部分（MIT，样式用 CSS Modules，无需 Tailwind）提供 button、split-button、segmented-control 等的写法与动效令牌（snappy / smooth / morph 弹簧）。Arc Pro 的 dock 是付费组件、不在仓库里，本项目按其公开行为说明自行实现，不复制其代码。 |
| beUI | **只参考动效写法** | Motion + Tailwind 的复制式组件（弹簧、模糊交叉淡入、布局过渡）。官方仓库与许可证未能确认。 |
| [RareUI](https://github.com/Codewithswappy/RareUI) · MIT | **主界面不用** | 液态、玻璃、3D、WebGL 背景等装饰性组件。与“图片底色保持中性、缩略图不加装饰”冲突：画师要靠眼睛判断参考图颜色。 |
| [Shaders](https://shaders.com) | **只用于“时刻”** | WebGPU 着色器特效。常驻界面（侧栏、顶栏、图片墙、查看器）与图片周围仍然不用：画师要靠眼睛判断参考图颜色，作画时也不能占显卡。2026-10-16（#78 人工验收反馈）放开到短暂的“时刻”：封印书的封印 / 释放演出、空状态、首次启动、导入完成。硬约束：演出结束或窗口隐藏即停止渲染；“减少动画”时给静态画面；没有 WebGPU 时退回 CSS 写法。用到哪一处需在对应工单里列明。 |

新增依赖只限 `@base-ui/react`、`motion`；`lucide-react` 已存在于原型。移植的 Fluid Functionalism 源码放在独立的 vendor 目录，文件头保留出处与许可证。任何新库都要先在这里登记许可证与用途。

## 品牌不变项

以下照原型原样移植，任何改版都不得换成通用图标或重画：

- 图标轨顶部的书签标（锁孔书签，`design/logo-kit/`，32 px 像素对齐，`fill: var(--ink)`）。
- 图标轨：56 px 宽、选中项左侧 3 px 樱粉指示条（跟随选中项滑动）、选中态 `--accent-soft` 底、深色数字角标。
- 封印书（安全模式开关，`prototype/reference-browser/src/sealbook.ts`，第五轮 A1 圆锁）与 `--seal-acc`（日间 `#C85672`，夜间金 `#E3B34F`）。
- 封印遮罩上的小圆锁（`lockSVG`），以及原型的封印 / 释放演出。

## 窗口框架

主窗口隐藏 Windows 原生标题栏。各列的标题行合成一条 56 px 的一体化顶栏，它就是窗口的安全区。

- **一体化顶栏**：图标轨顶端是书签标；侧栏标题行放图库切换与收起侧栏；主区标题行放查找框、张数、图片大小、导入；最右一列的标题行末尾放窗口控件。各标题行的空白处都可拖动窗口，双击切换最大化。
- **窗口控件位置**：控件永远在最右一列。打开详情面板时，它们移到详情面板标题行；此时详情面板的收起按钮用“收起面板”图标，不再用 ×，避免与关闭窗口混淆。查看器标题行同理。
- **控件规格**：最小化、最大化 / 还原、关闭；前面一条 1 px 分隔线；按钮 38 × 26 px、圆角 7 px、垂直居中；图形约 10 px，按设备像素绘制：边长取 10 × 缩放比例的整数像素，线宽取整数设备像素（100%／125% 为 1，150%／200% 为 2），横竖线边缘落在像素边界上，图形起点对齐整像素；斜线与圆角保留抗锯齿（`src/ui/winGlyphs.ts`）。
- **最大化**：控件去掉标题行右侧留白、贴住屏幕顶边与右边；按钮改为 38 × 32 px 直角、彼此无间隙，关闭按钮的点击区一直延伸到屏幕右上角。还原后回到上面的规格。Tauri（tao）已把最大化无边框窗口的客户区限定在显示器工作区内，页面右上角就是屏幕右上角，前端不需要再补偿越界边距。
- **状态**：悬停 `--hover` 底、`--ink` 色；按下 `--press`；关闭悬停 `#C94A4A` 底、`#FFFDF8` 图形；键盘焦点 2 px `--accent` 描边。最大化后中间按钮换成还原图形。
- **关闭语义不变**：关闭主窗口只关主窗口，Kinshoko 继续在托盘，截图、钉图与快捷键照常（见 ADR 0004）。
- **实现要点（Tauri 2）**：主窗口 `decorations: false`、保留 `shadow` 与可调整大小；各标题行加 `data-tauri-drag-region`，其中的按钮与输入框不拖动；控件调用 `getCurrentWindow().minimize()` / `toggleMaximize()` / `close()`，能力文件需对应 `core:window:allow-minimize`、`allow-toggle-maximize`、`allow-close`、`allow-start-dragging`。钉图、框选等无边框窗口不受影响。
- **已知取舍**：自绘按钮没有 Windows 11 悬停最大化按钮时弹出的贴靠布局；`Win + Z` 与拖到屏幕边缘贴靠仍可用。实施时在真机核对拖动、双击、调整大小、多显示器与 125%／150% 缩放。

## 侧栏布局

侧栏纵向分三段，长目录只在中间滚动：

1. **顶部固定**：全部图片、未归类。
2. **中间滚动**：每个图库一组（可折叠的组标题带状态点、张数、新建文件夹）；未连接的图库就地显示原因与“重新连接”；末尾是“含子文件夹”小开关（原型的位置）。
3. **底部固定**：后台任务（自动打标进度）与回收站。

行高 30 px，悬停高亮由 `use-fluid-hover` 驱动，在同一段内滑动；当前项用 `--accent-soft` 底与 `--accent-strong` 字。

## 按钮

- **分体按钮（导入）**：一颗墨紫胶囊，高 36 px、圆角 11 px。左半“导入”直接导入图片文件；右半 32 px 的箭头打开菜单：图片文件（Ctrl O）、整个文件夹、从 Eagle 导入，底部一行提示“也可以直接拖进窗口”，前面配灯泡图标，与上面各项的图标和文字对齐。整颗按下时缩到 0.97；箭头在菜单打开时转 180°。
- **信息区**：张数与图片大小合成一组低调的信息，不加底色，与操作按钮分开。
- **按钮层级**：墨紫实底只给本屏最主要的一个操作；其余用描边或无底；危险操作只在确认对话框里用红色实底。

## Dock

截图、查看器与框选的工具统一用一个浮动 dock（按 Arc Pro dock 的公开行为自建）：

- **外形**：半透明纸白底 + 18 px 背景模糊，1 px 细描边，圆角 18 px，内边距 6 px；每项 40 × 40 px、圆角 12 px，图标 18–19 px；组之间 1 px 分隔线。
- **选中**：一块共享的樱粉淡色块，用 morph 弹簧（0.42 s，回弹 0.16）在项之间滑动。
- **名称**：悬停或键盘聚焦时，墨紫小标签浮在上方，显示名称与快捷键，在项之间滑动；位置按实际布局测量。标签只作视觉提示，名称写在按钮的无障碍名称里（如“钉住局部，Enter”）。
- **按压**：按下缩到 0.9，snappy 弹簧（0.26 s，回弹 0.12）。
- **分组托盘**：如“背景”，从 dock 向上长出同材质的托盘，成员依次出现（间隔 35 ms）；当前项带樱粉描边。
- **读数**：框选与截图的 dock 左侧显示尺寸（原图像素 / 屏幕像素）。
- **主操作**：每个 dock 至多一个墨紫实底项（框选时“钉住局部”、截图时“钉住”）；取消悬停变红。
- **放置**：查看器 dock 固定在画面底部居中；框选与截图的 dock 跟在选区下方 14 px。
- **键盘与减少动画**：方向键移动、Home / End 跳到首尾、Enter / 空格执行，上键打开托盘、Esc 关闭；减少动画时位置直接跳到终点，只保留短淡入。
- **只放已有功能**：截图 dock 只有复制、钉住、取消；不加入正式程序没有的标注工具。

## 视觉与动效

- **令牌**：沿用原型配色（纸白 `#F7F3EA`、墨紫 `#2B2747`、樱粉 `#E0768F`；夜间墨紫底、奶油字、金色强调）与字体（Inter 4.1 + 思源黑体 SC VF）。
- **层级**：底 `--bg` → 面板 `--surface` → 下沉 `--sunken`（分段控件槽）；浮层统一 `--shadow-pop`、圆角 12 px；对话框 18 px。
- **圆角**：6 / 8 / 10 / 12 / 14 / 18 px，控件 8–10 px。
- **按钮两级**：普通（描边）与主要（墨紫底）；导入用樱粉强调；危险操作只在确认对话框里用红色实底。
- **动效**：弹簧曲线 `cubic-bezier(.2,.9,.25,1.05)`，浮层 220 ms 缩放 + 淡入，指示块 300 ms；图片本身只改位置与可见性（原型 #34 规则）。系统或设置开启“减少动画”时全部关闭。
- **图片区不加装饰**：瀑布流底色保持中性灰，角标只在必要时出现。

## 文案

- 名称 2–4 字，描述不超过 20 字，不用术语。原则依据《Don't Make Me Think》与《写给大家看的设计书》：一眼能懂、少即是多、相关的放在一起。
- 界面用“图库”，代码与文档继续用领域词“资料库”（见 `GLOSSARY.md`）。
- 完整对照见 [copy-map.md](copy-map.md)。
