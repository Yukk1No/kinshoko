# 玻璃 app 图标 · 夜间 / 樱粉（废案）

定稿用的是 R6（见 [`../../logo-kit/`](../../logo-kit/README.md)）。这两版留作参考：底板上有大团的彩色光斑，书签是半透明的浅色玻璃，整体更梦幻。樱粉版整块底板都是粉紫渐变，是角色感最强的一版。

## 构造

1024 画布，圆角矩形 `rx=228` 裁切全部内容。从后到前：

1. **底板**：斜向线性渐变，叠一层居中偏上的径向光（55% → 0）。夜间 `#332D5E → #141226`，配紫色光；樱粉 `#F79DB1 → #8A6BD0`，配浅粉光。
2. **光斑**：三个圆，用高斯模糊 70 晕开：左上 r150 75%，右下 r190 70%，右上 r90 60%。夜间是紫 / 玫红 / 金，樱粉是浅粉 / 紫 / 浅黄。玻璃透出的正是这些颜色。
3. **书签**：放在 `translate(160 154) scale(2.75)` 的 256 网格里。
   - **投影**：书签外形下移 14、右移 4，模糊 9，45% 不透明。
   - **玻璃体**：浅色斜向渐变（夜间 `#FFF7E6 → #EBC77E`、84% 不透明；樱粉 `#FFFFFF → #F3EAFF`、60%），锁孔挖空。
   - **锁孔深度**：只在锁孔内上色，深色由 55% 竖向淡到 10%，再加一圈下移 2、模糊 3 的暗描边，看起来像有内壁。
   - 以下效果都裁切在书签内：
     - **硬边**：3.6 宽的对角渐变描边，左上和右下亮、中段几乎透明。
     - **底部焦散**：椭圆 `70 × 34`，75%，模糊 9。
     - **顶部高光**：一块上沿平直、下沿弧形的面，白色向下淡出，45%。
     - **软边**：14 宽的白色描边，50%，模糊 3。
4. **星星**：中心 `(194, 46)`，半径 40，收腰 0.16。暖金渐变填充，同色 7 宽圆角描边让它更饱满；投影模糊 3。星内裁切一条 3 宽的白边，左上再点一颗小高光。星星压在书签右上角，形成第二层玻璃。
5. **底板边缘**：6 宽的白色描边，18%。

### 与定稿几何的差异

- **书签**更圆润：顶角 `r=34`（定稿 18）。V 口两侧和尖端都用二次曲线收圆（`Q192 241 175 229`、`Q128 192 119 199`）。
- **锁孔**槽底改成圆角（`Q146 158 139 158`），槽口略窄（145 / 111，定稿 147 / 109）。
- **星星**中心右移到 194，半径 40。
- 没有分层文件，也没有小尺寸版；光斑模糊半径很大，缩到小尺寸会糊成一片。若要复活，应按 R6 的方式拆成 背景 / 书签 / 星星 三层，并沿用 kit 的扁平小尺寸版。
