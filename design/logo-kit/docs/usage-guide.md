# Kinshoko Logo 使用规范 · v1.1

## 结构

主标为锁孔书签，自绘圆头字标中的 `i` 点为星星。横排用于标题栏与页头；竖排用于封面与居中版面。几何为固定 SVG 路径，使用现成组合并保持比例与字距。

安全距离从可见轮廓起算，四周至少留出 **X**；X 是当前字标的一倍笔画厚度，源几何为 22 单位。

## 颜色

浅底使用墨紫 `#2B2747` + 樱粉 `#E0768F`，推荐纸白 `#F7F3EA` 底。深底使用奶油 `#F4ECDC` + 金 `#E3B34F`，推荐墨紫底。单色用墨紫或纯黑，反白用纯白并配足够深的背景。

## 尺寸

- 横排宽度至少 120 px；竖排宽度至少 112 px。
- 16-20 px：micro，放大锁孔、去掉星星。
- 24 px：compact；32 px：small。星星加底色描边，与书签角分开。
- 三档小尺寸都按像素网格对齐，不要用标准图缩放代替。
- 40 px 及以上：标准扁平几何。
- 高 DPI 使用对应显示尺寸的 `web/png/retina` @2x / @3x 文件，或相应简化版 SVG。

## 使用范围

玻璃版使用已确认的 R6，适用于桌面图标、启动器和 Dock，显示尺寸 40 px 及以上。`app/native/` 的 ICO / ICNS 中 ≤32 px 的帧已是扁平版。三层按 0 背景、1 书签、2 星星顺序叠放，同坐标原点，保留锁孔透明与已有色散。

网页、favicon、标题栏和系统托盘使用扁平版。复杂背景先放在稳定底色上。

## 约束

保持比例；避免旋转、改变字距、填实锁孔，或自行增加阴影与描边。玻璃光效仅用于 app 图标。
