封印书 · F 书签化书（第三轮细化）

#27 · 封印态就是 logo 的锁孔书签；打开时书签两半直接变形为两页，底部 V 口落成书脊，锁孔先收拢，星最后出现。本页：主几何与 16 / 20 / 32 px 像素对齐几何、40 px 按钮各状态与图标轨、可打断的变形动画、图片墙特效草图、说明。所有按钮都可以点击。

动画中途再点一次会从当前形状掉头，不跳帧。

1 · 几何：24 主网格 + 16 / 20 / 32 px 专用像素对齐

每半边都是同一结构 M C A L A C Z（顶边、上外角、外边、下外角、底边），封印与打开只是数值不同，所以任意中间帧都是合法路径。锁孔、星的避让用 mask 挖空，按钮底色变化时不需要“假装底色”。

2 · 40 px 按钮与图标轨

按钮本身透明，悬停 7% 墨色底、按下 12% 并缩到 0.92、键盘焦点为 2 px 墨色 / 奶油描边（强调色在纸白上只有 2.7:1，不够做焦点环）。下表的状态用类名强制显示，按钮本身也能点。

3 · 变形动画（可打断）

打开：锁孔 0–170 ms 收拢；两页 0–460 ms 弹簧展开（右页晚 24 ms）；星 200–620 ms 旋入并轻微回弹。封上：星 0–140 ms 先收；两页 40–340 ms 合拢（无回弹，干脆）；锁孔 200–400 ms 落回，有一点“咔哒”的回弹。用 CSS d 过渡实现，中途反向时从当前形状出发。

4 · 延伸到图片墙（草图）

带“敏感”角标的是会被封印的图。封印：0.2 s 内糊掉并蒙上强调色（≤0.3 s 无法辨认），随后各自折成书签飞进左下角的书，其余图片 0.26 s 起连续补位，全程约 0.9 s。释放：书先打开、按钮处一圈光，图从书里依次飞出，带弧线和轻微放大落位，补位同时进行，约 1.2 s。参考组 / 钉图只在原位模糊，关闭时一张用“封印碎裂”，一张用“消散”，都不飞行。

5 · 说明

设计决定

  • 同构路径：每半边 7 段命令（M C A L A C Z），封印态的直边写成控制点在三等分点上的三次曲线；上外角用与 logo kit 相同的圆弧 A，下外角在封印态是半径 0 的圆弧。这样两页可以有真正的弧度，变形依旧是逐数插值，中间帧都是“半开的厚书”，不会出现自交。
  • V 口落成书脊：书签底部向上的 V 口，在打开态翻成向下的书脊弧线；顶边同样向书脊下沉。上下各沉 2 单位（24 网格），像纸页被装订线拉住。
  • 书往左偏半格：打开态的书轴在 11.5（24 网格），书缝正好是第 11 列一整列像素；同时把星的视觉重量平衡回来。
  • 星沿用 logo kit 的画法：同一条三次曲线四角星，24 / 32 px 有底色挖空，与 compact / small 星的关系一致；16 px 改成 3×3 像素十字。
  • 推荐变体 C：墨色书签 + 强调色锁芯。① 在图标轨里与其他墨色图标同分量，封印时不至于一直“喊”；② 锁孔被堵上 = 已锁，正好区分 logo（logo 的锁孔是空的）；③ 日间樱粉对纸白只有 2.7:1，整枚粉色书签达不到图形 3:1，墨色书签是 13:1。

与第二轮相比

  • 页面从平直平行四边形改成带弧度的纸页，上下外角都有圆角。
  • 新增 16 / 20 / 32 px 专用几何（第二轮全部是 24 网格缩放）；16 / 24 / 32 封印态与 logo kit 小尺寸逐像素比对（见第 1 节底部）。新增 20 px 封印书签。
  • 锁孔、星的避让从“画一块底色”改成 mask，按钮悬停 / 按下变底色也不会露馅。
  • 动效：打开 / 封上用不同曲线（打开弹簧、封上干脆），星与锁孔的先后顺序按方向反转，可从中途掉头；加了两页 24 ms 错开、悬停预示、减少动态效果。
  • 新增变体 B / C 与 logo 混淆的处理（锁芯）。
  • 新增图片墙特效草图与时序。

待确认

  • 封印态颜色：选 C（墨色 + 锁芯）还是 A（整枚强调色）？A 更醒目，但日间对比不足 3:1，且就是 logo 剪影。
  • 悬停预示要不要保留？它暗示“点了会打开”，但打开态没有对应的预示。
  • 两页错开 24 ms 是否保留？更像手翻，但稍不对称。
  • 实现：CSS d 过渡在 Chromium / WebView2、Firefox 可用，Safari / WKWebView 不支持。若 macOS 端用 WebKit，需要用 JS 按同样的数据逐帧插值（本页的分帧图就是这样画的），或用 SMIL。CSS 掉头只保证位置连续，不保留速度；想要更“物理”的掉头需用 JS 弹簧。
  • 图片墙：草图里封印的图折成书签飞回按钮。约 250 张时只给视口内的图做飞行，视口外直接隐藏。释放期间是否响应输入（Q110）未在此处理。
  • 16 px 的星改成像素十字，与 24 px 以上的曲线星不同形，是否接受？
