1 · 几何：24 网格母版 + 16 / 20 / 32 专用像素对齐版每行：1× 实际尺寸（封印 / 打开）→ 6× 像素放大（Chrome 实际栅格结果，非矢量放大）

链节：真链节，两种交替——正面环（长 4.6、宽 2.8、壁厚 0.95，中间镂空）与侧面环（长 3、宽 1.15 的实心短杆），节间留 0.6 空隙。每条臂从交叉点起按固定节距 4.4 排布：正 · 侧 · 正 · 侧；可见的是一个正面环跨在书角 / 书边上，外侧再露半截侧面环，读作“链子从书背后绕过来”。

45° 交叉：两条链都走正 45°，交叉点在 (12, 11)，比几何中心高 1，让挂锁的锁身落在中心偏下，重心稳。上臂正好擦过书的两个上角，下臂从书的左右两侧穿出——上紧下松，像挂锁把链子往下拽。

挂锁 = logo 锁孔：锁身 6 × 5（x 9–15、y 12–17，整像素），锁梁线宽 1、两腿落在整像素列（10–11、13–14）；第二轮的锁太大，压过了书，这一轮缩到书宽的 3/7；锁孔直接用 logo 书签锁孔的比例（圆头 + 梯形下摆），镂空透底。

留缝而不是描边：链、锁与书之间的 0.75 间隙用蒙版真正挖空（不是底色描边），所以悬停底色、强调底色、任意背景下都干净。正面环的孔也是透底的，夜间（金链 + 奶油书）因此仍分得开。

打开态：两页书 + 星，书脊缝 2 px（11–13）整像素；星沿用 logo 字标 i 点的四角星曲率（k = 0.16）。封印 → 打开时，合上的封面直接变形为两页（同一组路径插值），不是交叉淡化。

5 · 说明

设计决定

  • 链必须像金属链：放弃第二轮的虚线描边，改为正面环 / 侧面环交替的真链节。正面环中间镂空透底，是“链”与“绳 / 带子”最关键的区别。
  • 一条间隙规则：所有重叠处（链压书、锁压链、锁压书）统一 0.75（24 网格）挖空间隙；32 px 1.0，20 px 0.65，16 px 备选 1 px 整像素。间隙用蒙版做，所以按钮悬停底色变化时不会露出“描边色块”。
  • 颜色：封印态 = 墨色书 + 强调色链与锁（日间樱粉、夜间金）；打开态只剩墨色（日间墨紫、夜间奶油）。按钮在封印态再垫 15% 强调色底，作为 aria-pressed 的视觉对应。
  • 焦点环用墨色：樱粉对纸白只有约 2.6 : 1，达不到非文本 3 : 1，焦点环改用墨色 2 px + 2 px 外偏移。
  • 控件克制、墙面夸张：按钮本身的动效总长 ≈ 0.35 s（封印）/ ≈ 0.65 s（释放），只有一处小火花；夸张的“崩断”演出放在墙上。

16 px 怎么解决

  • 第二轮的问题：书 + 两条链 + 锁在 16 px 里只剩 1 列书边，链节和锁糊成一团。
  • 主方案 “锁 + 横链”：去掉书和交叉，只留挂锁 + 一条水平锁链（左右各一个 3×3 正面环 + 2×1 侧杆）。水平方向可以完全落在像素格上：环孔正好 1 个像素、锁梁两腿各 1 px、锁身 6×6、锁孔 2 px 宽。它和大尺寸是同一个意象的“徽记版”：锁 + 链 = 封印。
  • 备选 “书 + 锁”：保留书，只留锁不画链。更像“上锁的书”，但失去了本方向最有辨识度的链，和其它方向（如扣带）区分度变低。
  • 20 px 仍保留两条交叉链，但正面环不再开孔（孔只有 0.8 px 会变成半透明的灰点），改为实心椭圆 + 细杆交替，靠节奏读出“链”；锁梁线宽 1 px。
  • 16 px 打开态只用两页书 + 3 px 小星；星与书页留 1 px 缝。

和第二轮相比

  • 虚线描边 → 真链节；描边色块留缝 → 蒙版挖空。
  • 交叉点上移、锁身整像素，锁孔改用 logo 锁孔比例。
  • 新增 16 / 20 / 32 专用几何；16 px 改为锁 + 横链。
  • 动效从“同时淡入淡出”改为分部件的弹簧编排：封印 = 合书 → 链从对角线外滑入缠上 → 锁从上方落下扣合（锁梁“咔”一下）；释放 = 锁梁弹起 → 锁坠落 → 链条向外甩开（上臂变平、下臂下垂，像被重力拉走）→ 书翻开 → 星弹出。
  • 可中断：任何时刻反向，各部件从当前位置与速度继续，无跳变。

待确认

  • 16 px 选“锁 + 横链”（主）还是“书 + 锁”（备选）？前者更像本方向，后者更像“书”。
  • 图标轨其它图标若是线性图标，封印态这枚实心多色图标仍偏重（见第 2 节对比）；可接受吗？还是要做一版线性锁链（会更难缩小）？
  • 封印时普通图片是“飞进书里”还是原位消失？草图按“飞进书里”做，参考组 / 钉图原位模糊。被收走的图留下的空位是否保留（草图保留条纹空位），还是让剩余图片连续补位？
  • 日间樱粉锁在纸白底上对比约 2.6 : 1，靠墨色书撑起整体辨识；是否需要把日间强调色压深一点？
  • 释放时的小火花（按钮内）是否保留？去掉后控件更“精确”，但少了一点“崩断”的爽快感。
