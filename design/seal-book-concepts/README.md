# 封印书控件探索（#27）

图标轨底部的安全模式开关。封印态是合上的书加锁，打开态是翻开的书加 logo 星。

## 定稿：第五轮 A1 · 圆锁

见 [`round5-a1-round-lock/index.html`](round5-a1-round-lock/index.html)（截图 `index.png`，动效与图片墙截帧 `frames.png`）。

- **书**：按用户参考图简化。左上（书脊侧）大圆角，底部书页条，右下露出封底小脚；去掉封面标题横条。
- **锁**：圆形锁体加 U 形锁梁，锁体挖出 logo 锁孔，居中压在封面上，外围 1 格底色光环。24 网格锁体 Ø6；16 px 锁体实心、不挖锁孔（挖孔会读成“8”）。
- **打开态**：翻开的书加右上角四角星，不加书页条。
- **颜色**：封印态只有锁用强调色（日间深樱粉 `#C85672`，夜间金 `#E3B34F`），打开态只用墨色。日间改用深樱粉是为了让图形对比度在所有日间底色上 ≥ 3:1（原樱粉 `#E0768F` 只有 2.1–2.65:1）；按下态用中性底。
- **动效**：释放 640 ms（锁梁弹起转开 → 锁缩小消失 → 封面翻开 → 星出现），封印 420 ms 倒放并以锁梁扣合收尾，可中途反向；减少动态时直接切换。
- **验证**：各尺寸的 Chrome 栅格放大图、截帧已核对；按钮点击与中途反向未在真实浏览器手动测试。画师试用改为由用户自行试用。
