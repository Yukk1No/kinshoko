# Kinshoko 钉图试用说明

这是 Kinshoko 的**钉图试用版**，用来在正式版做出来之前，先替代 Snipaste 的钉图功能。资料库和找图继续用 Eagle，这个程序只负责“把图钉在屏幕上”。

它是试用版：功能不全，动画也比较粗糙，这些都在计划内。最有用的反馈是“哪里别扭、哪里不如 Snipaste、哪一步想做却做不了”。

## 开始

1. **先退出 Snipaste**：在任务栏右下角右键 Snipaste 图标，选退出。两个程序会抢同样的按键；不退出的话，也测不出这个程序能不能代替 Snipaste。
2. 双击 `kinshoko-desktop-pin-prototype.exe` 运行，不需要安装。会打开一个控制窗口，任务栏右下角也会出现图标。
3. 在控制窗口的“状态”页，勾选**“使用日志记录到本地文件”**。只需要勾一次，之后会一直开着。

关掉控制窗口就是退出程序；钉住的图会记住位置，下次打开时还在原处。

## 怎么用

| 想做的事 | 按键 |
|---|---|
| 截一块屏幕钉住 | `F1`，拖框选区，再按 `Enter`（或双击）。钉图就出现在截图的原位置。`Esc` 或右键取消 |
| 把复制的图片钉出来 | 在网页或 Eagle 里“复制图片”，然后按 `F3` |
| 暂时收起所有钉图 | `F4`：钉图全部滑到屏幕边，只露一条细边，可以直接继续画；再按 `F4` 全部回来 |
| 只看一下某张收起的钉图 | 鼠标碰一下屏幕边的细边，那张会滑出来，移开鼠标后滑回去 |
| 移动 | 按住钉图拖动 |
| 放大缩小 | 鼠标滚轮；双击回到原始大小 |
| 调透明度 | `Ctrl` + 滚轮 |
| 翻转、旋转 | 鼠标停在钉图上，右上角出现按钮；也可以按 `H`（左右翻转）、`V`（上下翻转）、`R`（旋转 90°） |
| 锁定、关闭 | 右上角按钮里的“锁”和“✕” |

**和 Eagle 一起用**：在 Eagle 里找到图，按 `F1` 截下来钉住；或者在 Eagle 里右键复制图片，再按 `F3`。截图时 Eagle 里显示得多大、多清楚，钉图就是什么样；想要更清楚，就先在 Eagle 里放大再截。

**截图历史**：控制窗口第一页保留最近 10 张截图，可以重新钉住，也可以点“收藏”保存下来。收藏的图在“资料库（原型）”页。这只是试用版的临时文件夹，不是正式资料库。

如果某个按键和优动漫冲突，在“状态”页点“更换”改成别的键。

## 一次性检查（抽空做一次，大约 30 分钟）

打开优动漫正常画画，用 `F1` 钉 2～3 张网上找的参考，逐项记下“通过”或“不通过”。数位板驱动的 **WinTab** 和 **Windows Ink** 两种模式各做一遍：

1. 钉图一直在优动漫上面，包括优动漫全屏时。
2. 在优动漫里画着画着按 `F4`：钉图收到屏幕边，笔马上就能接着画，不用先点一下画布。
3. 再按 `F4`，钉图回到原来的位置。
4. 钉图（没缩放、没翻转时）看起来和截图时屏幕上的一样清楚。
5. 关掉程序再打开，钉图还在原来的位置，翻转、旋转也还在。
6. `F1`～`F4` 和优动漫的快捷键有没有冲突；冲突时能不能改。

另外记一下电脑的**系统缩放比例**（设置 → 系统 → 屏幕 → 缩放）。

## 反馈要发回什么

- **日志文件**：在文件资源管理器的地址栏粘贴 `%APPDATA%\dev.kinshoko.prototype.desktoppin` 回车，把里面的 `PROTOTYPE-pin-events.log` 发回来。日志只记录按了什么、钉了几张、钉在哪里，不包含图片内容。
- **一次性检查的结果**：上面 6 项，每种数位板模式各一份。
- **日常感受**：随手记下哪里别扭、哪里不如 Snipaste，有截图更好。

想彻底清除试用数据，删掉上面那个文件夹即可。
