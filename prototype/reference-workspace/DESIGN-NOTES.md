# 参考工作区：设计说明

这是一次独立的领域交互试验：重新组织找图、取用和复用参考的流程，沿用现有视觉世界。A／B／C 都能操作，尚未选出正式方案。

资料库管理原图及参考图元数据；文件夹整理来源，允许一张图有多个归属；标签描述图像特征。查找只负责确定范围与条件，常用查找保存这些条件，下次根据当前资料重新查找。把这些放在来源侧，可以让整理结果服务多次绘画。

取用负责决定这次需要整图还是局部。局部可拖选，也可输入百分比，加入之前能核对预览及像素尺寸；原图仍保持完整。绘画参考区只管理已选参考的摆放、显示大小、叠放与位置锁定，裁切边界在取用阶段确定。独立参考组保存来源引用、各成员的范围与布局，能跨资料库再次打开，无须重新选图，也不会因保存组而复制原图。

| 方案 | 实际结构 | 要试的问题 |
| --- | --- | --- |
| A 专注取用 | 找图 → 取用 → 绘画参考，每次一个完整视图 | 阶段切换是否减轻信息负担？ |
| B 查找台 | 图片墙与下方本次参考托盘；取用打开聚焦弹窗，摆放进入完整参考区 | 是否便于连续比较、累积参考？ |
| C 并排工作台 | 桌面同时展示图片墙与绘画参考区，可展开参考区；手机用「找图／绘画参考」分段切换 | 同时查找和摆放是否值得占用图片墙宽度？ |

三种方案共用查找条件、取用结果、文件夹、标签和参考组状态。取出局部后继续找图会返回原有条件、浏览位置与所选图焦点；切换资料库保留本次参考。这让比较聚焦于任务结构，而非重新准备数据。

视觉沿用炭灰／浅灰底面、低饱和橄榄色选中与焦点、Windows／中文系统 UI 字体栈、Lucide 图标轨，以及克制的 180ms 控件颜色过渡。图片自身承载颜色，TanStack Virtual 瀑布流继续按原比例排列。桌面侧栏可收起；720px 内将分类移入弹窗；图片墙继续按可用宽度排列，390px 与 553px 截图中为两列。A 按阶段聚焦，B 留较短托盘，C 每次显示一个主要任务。窄屏取用面板可纵向滚动，范围、预览和加入操作仍可到达。

缩略图和整图查看保持完整比例；局部预览只展示明确选定的范围。绘画参考窗口等比显示选区，显示大小与裁切边界各自独立。原图像素没有用于悬浮或切换的装饰动画；系统减少动画设置关闭控件过渡。

文件夹默认包含后代、多标签与文字词项按同时满足（AND）查找，均是本次 UI 假设，没有形成新的 ADR。资料库／参考组关系继续遵守根 GLOSSARY.md 与 ADR 0002。

所有状态只在内存中，刷新即重置。本地 PNG／JPEG／WebP 只在本次浏览中读取；公开作品和自制几何样本共用旧样稿素材，标签由人工编写。网页参考窗口模拟桌面置顶，未确定正式 Tauri 组合或存储格式；本次记录不推导原生置顶、ICC／DPI、自动打标、备份、同步或大图库性能结论。

根 DESIGN.md 与 .impeccable/design.json 保持原样，仍记录 library-browser 的视觉系统和候选布局。本表面的 13px 继承基准、8px 图卡圆角及 ease-out 缓动相对旧文档有局部差异，仅在此记录，不推广为全局 token。核对文件、12 张实际截图和保留校验见[文档证据](../../.impeccable/review/reference-workspace/documentation.md)；运行范围见[验证记录](../../.impeccable/review/reference-workspace/verification.md)。
