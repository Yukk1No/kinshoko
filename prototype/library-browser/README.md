# 资料库浏览交互原型

这是可丢弃的网页样稿，用来比较图片墙、筛选优先与观察优先三种结构。没有正式资料库存储、Tauri 窗口、自动打标或备份恢复。

## 启动

需要 Node >=22.12 与 pnpm 11.19.0。首次安装 `pnpm install --frozen-lockfile`，随后在本目录运行：

```powershell
pnpm demo
```

打开 http://127.0.0.1:4174/prototype/library-browser?variant=A 。底部样稿切换条可以换 A／B／C；URL 保留结构，开发辅助条在 production build 隐藏。两侧方向按钮和 body 上的左右键循环切换，输入框、图片和查看器的按键不被它截获。

- A：全窗瀑布流与大图覆盖查看。
- B：搜索／筛选先行，选中后内联查看（窄窗口覆盖）。
- C：左侧大图观察，右侧瀑布流结果（窄窗口上下分区）。

## 可以验证

图标导航、轻量指示动效、减少动画、浅／深模式；完整构图的 TanStack lanes 瀑布流；等尺寸布局对照；密度、极长图限高；100／1,000／10,000 条构造记录；手工示例标签／名称筛选与排序；单项坏图；图片 ID、键盘焦点、查看／缩放、滚动返回和窗口改宽。

资料库图标里可切换空白状态、构造样本和本地试排。通过文件选择／拖放把 JPEG、PNG、WebP 解码到内存，使用浏览器方向修正后的自然尺寸。样稿不修改源文件；关闭／刷新后清空。文件格式、动画与色彩的正式导入策略另行验证。

样稿状态显示匹配数量、挂载卡片 DOM、列数、滚动偏移、选中与焦点 ID。虚拟列表保留一个焦点卡片，其余挂载范围由库处理；极端比例可能扩大范围，不能宣称固定 DOM 数量。

## 证据边界

构造数据复用少量[公开绘画与几何夹具](public/samples/SOURCES.md)，元数据／标签是手工示例，不代表万张独立图片解码或自动标签准确率。公开素材打包的是 Commons 缩小预览；样本附来源元数据，本地试排不写源文件。原图查看指查看打包的样本文件或本次选定的本地文件，不代表下载了馆藏原始扫描。

“原始尺寸（CSS）”为一个图像像素对应一个 CSS 像素，不宣称高 DPI 物理像素 1:1。浏览器默认色彩／EXIF 显示不构成原生 WebView2、ICC、GPU、DPI、置顶窗口或正式恢复的验收证据。

`pnpm typecheck` 与 `pnpm build` 核验组合编译。原型无正式工程测试基线，后续正式工程保留验证结论并单独评审实现，不直接以样稿作为生产存取层。

## 固定依赖

2026-10-03 核对 npm 官方发布元数据：React／DOM 19.3.0（MIT）、TanStack React Virtual 3.14.13／core 3.17.11（MIT）、Lucide React 1.50.0（ISC）、Vite 8.3.2／React plugin 6.1.1（MIT）、TypeScript 5.9.3（Apache-2.0）。Vite／插件 Node 要求 >=22.12，实际以锁文件和运行命令为准。布局、测量及虚拟范围复用 TanStack；仅图片控件、筛选／身份／焦点／滚动锚点由样稿接入。

## 回位机制与限制

静态卡片高度直接来自尺寸元数据和固定 CSS，高度估值与渲染值一致；不逐卡 DOM 测量。数据／列宽改变时 TanStack 重建几何，画布的 React 提交版本确认新尺寸已提交后再滚动；不使用可能损失小数的 CSSOM 高度字符串作为完成条件。查看关闭、深滚动、删后邻近项、改宽与结构切换共享此路径。

请求的焦点卡片必须已经挂载、祖先不再 inert，且浏览器实际 activeElement 指向该卡片才算完成。尚未满足时保留请求，等待相关提交；没有定时轮询或重复滚动补偿。空结果保留上一次有效锚点，跨 A／B／C 重挂载时传入该锚点；锚点消失时找原排序中的现存邻近项。资料库切换主动清除上下文。浏览器画布／滚动尺寸上限和原生 DPI 仍不属于这轮验收。
